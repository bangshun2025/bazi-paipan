## 2. 新增内容

工具栏新增「📋 复制盘面」按钮：一键把当前盘面复制成结构化纯文本，粘贴给任意 AI 即可续聊。

- 文本口径与盘面同源：`RENDER.buildAiCopyText(data)` 复用 `renderChart` 的柱增强逻辑（十神/藏干/纳音/星曜/自坐/空亡/日柱神煞），结构为【八字盘面】头部 →【四柱】逐柱明细 →【三垣】→【其他】生肖/人元司令 →【起运】+交运时刻 →【大运】十步 →【当前】现行大运+流年 →【宫位标注】（仅输出已勾选组，标签按 GW_INDEX 槽位取词）。
- 隐私口径：姓名只用 displayName（备注名），真实姓名不落文本；未排盘时点击仅浮提示「请先排盘，再复制盘面」。
- 复制实现：clipboard API 优先，失败回退 execCommand textarea；成功浮 tip「盘面已复制，去粘贴给 AI 吧」。
