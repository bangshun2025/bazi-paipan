**v0.57.0（MINOR）**。本次发布一个 commit 同时携带两版内容：

## 2. 新功能内容

**v0.56.0 运列表头年份**

- 大运/流年列表头在干支下加干支年份小字（`.dyln-yr`），`dyLnYearHtml` 顶层辅助函数统一渲染，三产物 CSS 同步。

**v0.57.0 多选岁运**

- 工具栏「☰ 多选岁运」按钮（active 态高亮），开启后大运格/流年格进入勾选语义：两大运 + 各自多流年。
- `applyMultiDL(container, data)` 渲染后 DOM 插列：原 `col-ln` 列复用为第一个流年列，插大运二列与流年扩列，`col-dy2` 标识；状态机 `setMultiDLState` 关闭恢复 7 列基线。
- 调试中修复两个实现 bug：三垣 hd 行尾两列是 `td` 非 `th`（`'th,td'` 混选 + 插列标签按区选）；星曜行类型 `xingyao xy1` 正则须 `\bxy\d\b`。
- 断言：MLT 新增 18 条（三垣 hd 混选、星曜 data-xy-gz、colspan、状态机、关闭恢复等），总断言 1396 → 1414。
- 正常模式 UI 实测 8/8 全绿（CDP 真实点击：按钮 active → 勾大运 1/4 → 勾流年 1999/2001 → 表头 9 列 → 关闭恢复 7 列）。
