## 2. 本版内容

**A. 示例盘（新增，`localStorage['bz_gen_examples']`）**
- 与正式档案 `bz_archives_v2` 完全隔离；造盘成功即自动存入，无需手动保存
- 同「特征 + 四柱 + 性别」去重置顶，上限 60 条；顶部「📚 示例盘」带条数角标
- 点一条按年月日时**现算整盘**重开（大运/起运齐全），不存快照 —— 引擎升级后旧示例不变脏
- 单条删除、一键清空（明示不影响档案）；横幅「⭐ 转存档案」才真正写进档案

**B. 解析增强（`ALGO.GEN.parse` 重写）**
- 归一化（全角转半角、常见繁体转简体）、柱位（月柱七杀/时干正官）、精确计数（正好两个）
- 十神组（官杀透两干）、点名干支（寅透甲丙戊）、五行认局（三合水局→申子辰）
- 多特征组合（顿号/且/和 → `and`，命中后完整 `paipan` 复核）、否定（不冲）、性别口令
- 认不出给 3 条「是不是想说」候选可点选，不硬猜；`scan` 加 `variant` 支持 🎲 换一张
- `PATTERNS` 扩到 17 个 chip；新增 `HELP` 句式清单

**C. v0.97.0 特征造盘（本次随版发布）**
- 一句话描述干支结构 → 按真实出生时刻扫描命中盘；一日一发 `paipan` 取三柱 + 五鼠遁补十二时辰
- 命中后完整复核；起点按描述散列（同句稳定、不同特征散落年代）；跳过未出生日期
- 只渲染不写档案；`render.js` 的 `doPaipan` 入口收起造盘横幅

## 7. 遗留

1. **FLK Z03/Z04 视口假象**（v0.94.1 起记录）：窄窗口下两条布局断言失败，宽窗口不复现。建议未来给这两条断言加窗口宽度前置条件，避免每次发布都要解释。
2. **示例盘不跨设备**：存 `localStorage`，换设备/换浏览器不可见（与档案不同，档案有云端）。若日后需要云端同步，需加一张表。
3. **解析仍是规则 + 词表**：覆盖主流术语与常见口语变体；「任意中文都懂」需模型参与，不在本次范围。认不出时会明说并给候选，不给错的盘。
