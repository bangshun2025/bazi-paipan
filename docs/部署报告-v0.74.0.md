## 一、本版内容

**需求**：流月、流日都调整成「从左到右、再换行」的顺排。

**旧行为**：`perColumn = Math.ceil(n / 6)` 把 12 个月按列切片——第一列一月、二月，第二列三月、四月。视觉上是竖着读完一列再读下一列，横着读第一行是「一月 三月 五月 七月 九月 十一月」的隔月序列。

**新行为**：横着填满六格再换行。

```
流月   一月   二月   三月   四月   五月   六月
       庚寅   辛卯   壬辰   癸巳   甲午   乙未
       七月   八月   九月   十月   十一月  十二月
       丙申   丁酉   戊戌   己亥   庚子   辛丑

流日   10/8  10/9  10/10 10/11 10/12 10/13
       10/14 10/15 10/16 10/17 10/18 10/19
       …
       11/7
```

## 二、实现

只改 `render.js` 的 `flowTable`，td 骨架与 CSS 一律不动：

```js
// 旧：按列切片
var perColumn = Math.ceil(items.length / 6);
var entries = items.slice(columnIndex * perColumn, (columnIndex + 1) * perColumn);
var index = columnIndex * perColumn + entryIndex;

// 新：行交错取
var rowCount = Math.ceil(items.length / 6);
var entries = [];
for (var rowIndex = 0; rowIndex < rowCount; rowIndex++) {
  var at = rowIndex * 6 + columnIndex;
  if (at < items.length) entries.push(at);
}
var content = entries.map(function(index) { var item = items[index]; … });
```

第 `columnIndex` 列拿到的下标是 `columnIndex, columnIndex + 6, columnIndex + 12, …` —— 竖着看是隔 6，横着看就是连续。
