# 实施记录 · v0.33.0 档案列表按名字拼音排序

日期：2026-09-12
版本：v0.32.0 → v0.33.0
范围：`archive.js` / `index.html` / `standalone.html` / `standalone-split.html`

## 需求（原话）

「很好，档案的名字需要按拼音顺序来排序」

## 实现

### 排序键
- 新增 `archiveSortKey(a) = getDisplayName(a)` —— **排序键就是列表里看到的那一行名字**，所以「看到的顺序 = 拼音顺序」
  - 隐私关：`小名 / 姓名`（无小名则姓名）
  - 隐私开：`艺名 → 小名 → 匿名`
- 新增 `sortArchivesByName(archives)`：中文按读音 `localeCompare(x, 'zh')`；显示名相同 → 按正名（姓名）拼音 → 再按 `updatedAt` 新在前
- 脏数据兜底：缺字段 / `null` 条目不抛错；无名字段在隐私开时回落「匿名」、隐私关回落 `''`

### 接入点
- `renderArchiveModal()`：原 `updatedAt` 倒序 → `sortArchivesByName()`，**排序后仍 `saveArchives()` 写回**

### 为什么必须写回（关键约束）
行内 `✏️ 修改 / 🗑️ 删除 / 排盘` 按钮都是 `onclick="...(索引)"`，索引指向 `getArchives()` 的数组下标。
若「显示顺序」与「落盘顺序」不一致，点击任何一行都会操作到别人。故本次保持既有不变量：
**落盘顺序 ≡ 显示顺序**。既有寻址方式（数组索引）未改动，改动面因此最小。

### 边界
- 排序幂等：打开弹窗 / 切标签 / 搜索 / 切隐私开关均会重排，结果一致
- 同名（显示名相同）不会乱序：按姓名再按更新时间兜底
- 拉丁名（如 `KK` / `NONO`）在 zh 排序规则下排在汉字之后，属 ICU zh 正常行为，未做特殊处理
