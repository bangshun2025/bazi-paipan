# PRD v0.16.1 — 档案弹窗布局优化

> **版本**：v1.0
> **日期**：2026-08-07
> **作者**：产品经理
> **状态**：待评审
> **关联源码**：archive.js（renderArchiveModal / filterArchives）、standalone-split.html（archive-modal CSS）

---

## 需求背景

当前档案弹窗（archive-modal）max-width 仅 420px。单行布局为：

```
[小名 / 大名 ♂ 2026年08月07日 12:00] [✏️ 修改] [🗑️ 删除] [排盘]
```

行内塞了四个信息区：名字区、性别图标、完整日期（年月日时分）、三个操作按钮。当名字较长（如「小名 / 大名」组合）时，名字列被 `text-overflow:ellipsis` 截断，大名直接看不见。

邦顺反馈：「档案页面太窄，已经看不到左边名字了。中间生日只留年就好，月日时不要了。一定要确保大名和小名都能看得见。」

### 根因分析

| 因素 | 现状 | 影响 |
|------|------|------|
| 弹窗宽度 | max-width: 420px | 总空间不足 |
| dateStr 格式 | `2026年08月07日 12:00` | 占用 ~14-16 字符宽度，挤占名字空间 |
| 操作按钮 | 三个按钮（修改/删除/排盘） | 固定占用 ~150px |
| 名字列 CSS | `white-space:nowrap; overflow:hidden; text-overflow:ellipsis` | 空间不足时直接截断 |

---

## AC 验收条件

- [ ] **AC-1**：档案弹窗中，每条档案行仅显示「年份」，格式为 `YYYY年`（如 `2021年`），不再显示月、日、时、分
- [ ] **AC-2**：大名和小名在正常长度下完整可见（以自在班16孩预置数据中最长的「小名 / 大名」组合验证——见测试要点）
- [ ] **AC-3**：`filterArchives()` 搜索结果行与 `renderArchiveModal()` 完整列表行，dateStr 格式保持一致
- [ ] **AC-4**：弹窗宽度不变（保持 max-width: 420px），仅通过缩短日期栏释放空间
- [ ] **AC-5**：档案编辑弹窗（edit-dialog）不受影响——编辑弹窗内日期字段仍然显示完整年月日时分，可正常修改
- [ ] **AC-6**：档案数据存储不变——`year/month/day/hour/min` 字段完整保留，不丢失任何信息

---

## 影响范围

### 代码段

| 文件 | 函数/区域 | 影响类型 | 说明 |
|------|-----------|----------|------|
| `archive.js` ~740 行 | `renderArchiveModal()` | **修改** | `dateStr` 从 `a.year + '年' + a.month + '月' + a.day + '日 ' + pad(a.hour) + ':' + pad(a.min)` 改为 `a.year + '年'` |
| `archive.js` ~790 行 | `filterArchives()` | **修改** | 同上，保持两处 dateStr 生成逻辑一致 |
| `standalone-split.html` | `.archive-row-date` CSS | **无需修改** | 当前 `font-size:12px; white-space:nowrap` 对短文本完全适用 |
| `standalone.html` | 同上 CSS | **同步修改** | 内联版需与 split 版保持一致 |

### 受影响的已有功能

- **档案搜索**：`filterArchives()` 中有独立的 dateStr 生成，需同步修改（否则搜索结果行与完整列表行日期格式不一致）
- **16孩预置数据**：仅影响展示，不影响数据本身。预置档案的 month/day/hour/min 仍完整保留
- **编辑弹窗**：不受影响。编辑弹窗走独立表单，不引用 dateStr

---

## 非目标（明确不做）

- ❌ 不修改弹窗宽度（max-width 保持 420px）
- ❌ 不修改操作按钮数量、样式或排列方式
- ❌ 不修改数据结构（Archive 对象的 year/month/day/hour/min 字段完整保留）
- ❌ 不修改编辑弹窗中的日期显示或编辑逻辑
- ❌ 不涉及排盘功能、大运流年、宫位等其他模块
- ❌ 不修改 standalone.html 中除 dateStr 外的任何内容

---

## 测试要点

### 边界 case

- **最长名字组合**：自在班16孩中「二哥 / 何沛润」「茂茂 / 甘志茂」「成哥 / 肖竟成」——验证「小名 / 大名」完整可见，无截断
- **单名（无小名）**：手动录入只填姓名不填小名，验证仅显示大名不截断
- **搜索过滤后**：输入关键词搜索，搜索结果行日期格式与完整列表一致（仅年份）
- **农历档案**：农历录入的档案，dateStr 同样仅显示公历年份

### 回归风险点

- **编辑弹窗中的日期字段**：打开编辑弹窗，确认月、日、时、分字段完整可见且可正常编辑
- **修改档案后保存**：修改日期后保存，档案行日期仍仅显示年份，但数据完整保存
- **加载到排盘表单**：点击「排盘」按钮，表单中的年月日时分完整回填，排盘结果正确
- **16孩预置数据排盘结果不变**：16孩预置档案的八字四柱计算结果不受影响
