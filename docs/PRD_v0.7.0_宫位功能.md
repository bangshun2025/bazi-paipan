# PRD：v0.7.0 宫位功能

## 版本信息
- 版本号：v0.7.0
- 发布日期：2026-07-15
- 依赖版本：v0.6.7（龙凤流年着色修复后）
- 改动范围：standalone.html（纯 UI 层，不改排盘算法）

## 功能概述

新增**宫位视角切换器**：14 种宫位类型可选，选择后在七柱（胎元/年柱/月柱/日柱/命宫/时柱/身宫）上方显示对应的宫位标签行。

一句话：给每根柱子贴个标签，让用户从不同视角理解七柱的含义。

## 二、UI 交互设计

### 2.1 下拉选择器

**位置**：紧贴四柱/卡片表格上方，与"精简"按钮同一行或独立一行。

- **单人视图**：`<table class="chart">` 上方，`.btn-simple` 同行右侧。
- **双胞胎视图**：并排卡片整体上方，`.bz-twin-tabs` 同行右侧。

**默认值**：`无（默认视图）`——不选中任何宫位类型时，不显示标签行（即现有行为完全不变）。

**交互**：
- 下拉选择后**即时切换**——无需重新排盘，纯 JS/DOM 操作更新标签行文字。
- 下拉列表结构：`<select>` 共 15 个 `<option>`：1 个 `无` + 14 种宫位类型（名称）。

**样式**：与现有 `.btn-simple` 风格一致——`font-family: var(--font-display)`，13px，`border: 1px solid var(--c-line)`，`background: var(--c-paper)`。

### 2.2 宫位标签行

**位置**：在七柱的**柱名行（`<tr class="hd">`）之上**，新增一行专属标签行。

- 单人视图主表：`<tr class="hd">`（年柱/月柱/日柱/时柱/大运/流年）之上新增 `<tr class="gz-tags">`
- 单人视图三垣表：三垣 `<tr class="hd">`（胎元/命宫/身宫）之上新增 `<tr class="gz-tags-sy">`

**标签行结构**：

主表（7列）：
```
<tr class="gz-tags">
  <td class="rl"></td>     <!-- 盘式列留空 -->
  <td>信息输入</td>         <!-- 年柱 -->
  <td>信息处理</td>         <!-- 月柱 -->
  <td>意义判定</td>         <!-- 日柱 -->
  <td>输出组织</td>         <!-- 时柱 -->
  <td class="sep"></td>    <!-- 大运分隔列留空 -->
  <td class="col-ln"></td> <!-- 流年列留空 -->
</tr>
```

三垣表（3列有效）：
```
<tr class="gz-tags-sy">
  <td class="rl"></td>     <!-- 盘式列留空 -->
  <td></td>                <!-- 占位列留空 -->
  <td>状态门控</td>         <!-- 胎元 -->
  <td>情绪标记</td>         <!-- 命宫 -->
  <td>执行反馈</td>         <!-- 身宫 -->
  <td class="sep"></td>
  <td class="col-ln"></td>
</tr>
```

> **关键规则**：标签行只对七柱有效列填充文字，大运/流年/占位列始终留空。

**样式规范**：
```
.gz-tags td, .gz-tags-sy td {
  font-family: var(--font-body);
  font-size: 12px;
  color: #8b7e6a;          /* 与现有 meta 色一致 */
  background: rgba(201,169,110,.06);  /* 与 rl 列背景呼应 */
  padding: 4px 3px;
  letter-spacing: .04em;
  border-bottom: 1px dashed var(--c-line);  /* 虚线与下方柱名分隔 */
}
```

### 2.3 双胞胎视图适配

双胞胎卡片视图（`buildCardHTML`）中，每张卡片内也有四柱表 + 三垣区，需各自叠加标签行。规则同单人视图——下拉选择器切换时，两张卡片的标签行**同时更新**（同一组七柱，同一套宫位标签）。

龙凤胎视图中两张卡片各自独立大运表，但宮位标签行针对的是七柱（胎元/年柱/月柱/日柱/命宫/时柱/身宫），与性别无关，两张卡片的标签行内容完全一致。

### 2.4 精简模式交互

- "简"按钮（精简模式）影响纳音/空亡/神煞行，**不影响宫位标签行**。
- 标签行始终显示（当选中某宫位类型时），不受精简模式切换影响。

## 三、技术约束

| 约束 | 说明 |
|------|------|
| 不改排盘算法 | 纯 UI 叠加，零算法改动 |
| 不改数据结构 | `_paipanData` 等现有对象不做任何扩展 |
| 单选 | 同一时刻只能选一种宫位类型，不可多选 |
| 默认无标签 | 初始加载/排盘后不显示标签行，用户主动选择后才出现 |
| 即时切换 | `<select>` onchange 事件驱动，无需重新排盘 |
| 映射表数据 | 映射表硬编码为 JS 常量对象 `GONGWEI_MAP`，14 键 × 7 值 |

**映射表 JS 数据结构**（供架构师参考）：

```js
const GONGWEI_MAP = {
  '信息': ['状态门控','信息输入','信息处理','意义判定','情绪标记','输出组织','执行反馈'],
  '认知': ['生理状态','感知输入','思考加工','认知决策','趋避决策','表达输出','行动输出'],
  // ... 其余12种
};
// 索引顺序：胎元, 年柱, 月柱, 日柱, 命宫, 时柱, 身宫
```

**js 函数签名草案**：

```js
function updateGongWeiTags(type) {
  // type: null → 隐藏所有标签行
  // type: '信息' / '认知' / ... → 更新所有标签行文字
  // 操作 DOM：querySelectorAll('.gz-tags td, .gz-tags-sy td')
}
```

## 六、风险与注意事项

1. **双胞胎视图的 DOM 选择器**：标签行更新需同时命中所有 `.gz-tags` 和 `.gz-tags-sy` 元素（单卡2个表，双卡4个表）。使用 `querySelectorAll` 批量操作。
2. **龙凤胎视图差异**：龙凤胎两张卡片的大运表因性别不同而异，但宫位标签行针对的是七柱（与性别无关），两张卡片标签一致。
3. **表格列对齐**：标签行必须与下方数据行的列数、colspan 完全一致，否则表格错位。实现时建议完全复用 `buildCardHTML` / `renderChart` 中已有的列结构模板。
