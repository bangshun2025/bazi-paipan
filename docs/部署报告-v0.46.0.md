## 2. 修复内容

旧实现用 `出生年 + Math.round(起运总月数/12)` 取首个大运起始年，丢掉了起运的月与日，判据退化为「起运余月是否 ≥6 个月」，与「交运是否跨日历年」并不等价：余月 ≥6 且不跨年时整体晚一年，余月 <6 且跨年时整体早一年。

新实现：`ALGO` 新增 `addYMDH`（自然月加法，目标月天数不足时对齐月末，如 3/31 + 1 月 = 4/30）；交运时刻 = 出生时刻 + 起运 年/月/天/小时；第 i 步 `startYear = 交运年 + i×10`、`startAge = (交运年 − 出生年 + 1) + i×10`；`qiYun` 输出 `jyYear`。渲染层同源：运前列年数由 `Math.ceil(总月数/12)` 改为「交运年 − 出生年」，与 `daYun[0].startYear` 单源；三处卡片版同步。

新增 21 条断言：29 条错位样本表驱动、单点首运年与虚岁、十步跨 90 年连续性、`addYMDH` 月末对齐、运前列与首运年 DOM 衔接。
