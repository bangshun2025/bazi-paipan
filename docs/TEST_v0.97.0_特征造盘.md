## 3. 关键口径

- **不落档案**：造盘只 `renderChart` + `setCurrentBaziResult`，不调 `autoSaveArchive` / `saveLastChart`（D9/E3 实测档案条数恒定）；用户点「排 盘」才入档，此时横幅自动收起（F3）。
- **十神自算**：`ALGO.GEN.ss` 不依赖全局 `TAIJI`，用户盘上的太极点不会改写造盘判据（断言 29）。
- **扫描必须走 `paipan`**：一日一发完整排盘取年月日三柱，立春/节气换月由引擎处理；命中后完整复核一次（断言 27 守住 2000-01-01 仍是己卯年）。
- **起点散列**：由描述文本决定起点年月日时，同一句话结果稳定、不同特征散落在整个年代范围（不会每次都给同一天），并跳过未出生日期（断言 26）。
