## 一、本版内容：竖线上下对齐

**需求**：天干行的竖线与藏气层的竖线要上下对齐，视觉上一条线贯下来。

**原因**：两个渲染单元各按自己的字号换算 em 间距。

| | 字号 | 十干区左间距 `.3em` | 竖线前后 `.4em` | flex gap |
|---|---|---|---|---|
| 天干单元 `.ssh-g-l` | 28px | 8.4px | 11.2px | `.12em` = 3.36px |
| 藏气单元 `.ssh-cg-l` | 17px | 5.1px | 6.8px | `.1em` = 1.7px |

同一个 em 值落到像素上差一倍；再加上十干区宽度随词宽变化，竖线位置逐柱、逐层漂移。实测天干行竖线比藏气行右 **20.13px**。

**修法**：间距从 em 换成定值，十干区固定宽。

| 项 | 原 | 改 |
|---|---|---|
| 十干区宽 | 随词宽（空占位 `1.1em`，28px 下 30.8px） | `font-size: 10px; min-width: 34px`（两行同宽） |
| 十干区左间距 | `.3em` → 8.4 / 5.1px | `8px` |
| 竖线前后 | `padding .4em / margin .4em` → 11.2 / 6.8px | `padding 8px / margin 8px` |
| 天干行竖线 margin | `.4em` @28px = 11.2px | `6.3px`（补 flex gap 差 3.36 − 1.7 = 1.66px） |

对齐的物理基础：竖线左侧的累积宽度两行本就几乎相等——

- 天干行：`28（天干）+ 3.36（gap）` = **31.36px**
- 藏气行：`17（藏干）+ 1.7 + 11（十神）+ 1.7` = **31.4px**

差 0.04px，所以只要把后段间距统一，竖线自然落在同一 x 上。

过程中发现一个 CSS 覆盖问题：`.gy-sep` 与 `.ssh-g-ns` 同为单类选择器、`.gy-sep` 在后面，会把天干行的 margin 覆盖回 8px。补 `.ssh-g-ns.gy-sep { margin-left: 6.3px }`（双类，特异性更高）才生效。
