## 2. 本版内容

### 2.1 人元司令跨年子月修复
- **现象**：1988-01-05 05:00（小寒前一日）生辰，对比卡整行人元司令不渲染
- **根因**：该日属上年（1987）子月，原 `algorithm.js renYuanSiLing` 子月起始节气大雪只取当年（stY=y），搜索窗口错为 [1988 大雪, 1989 小寒]，出生时刻落不进任何节气窗口 → 返回空串 → `render.js` 对比卡 `meta.siLing` 为空则整行不渲染
- **修复**：stY 改为 ∈[y-1, y+1] 三年候选搜索，原丑月小寒特判并入通用循环（删分支、逻辑归一）；司令表口径未动
- **锚点**：1988-01-05 05:00 → 「癸（大雪后 28 日）」（大雪后 28 日仍在癸管辖，跨年判定正确）
