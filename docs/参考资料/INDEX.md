## 01 · 坐X 与 X坐 十二长生口径定义（2026-10-02）

### 本篇立了什么

- **X坐**（年坐/月坐/时坐/胎坐/命坐/身坐）：固定 **X 柱天干**，对每一个地支求十二长生——固定干、遍历支。
- **坐X**（坐年/坐月/坐日/坐时/坐胎/坐命/坐身）：固定 **X 支**，对每一个天干求十二长生——固定支、遍历干。
- 两组互为**转置对称**。

### 与现有实现的差异表

实测环境：当前档案盘 壬戌 庚戌 甲戌 丁卯｜大运甲寅｜流年丙午｜胎年辛酉 胎元辛丑 命宫甲辰 身宫壬寅，用项目 algorithm.js 真 changSheng 逐值枚举（/tmp/enum_zuox_v0432.js，用完即删）。

| 项目 | 现有实现（render.js） | 本篇口径 | 结论 |
|---|---|---|---|
| X坐组四柱区（zuoRowMain） | 每列=changSheng(X干,该列支)，含大运流年列 | 一致 | ✓ 一致（实测年坐六值全对拍） |
| X坐组三垣区（zuoRowSy） | 每列=changSheng(X干,三垣各支) | 一致 | ✓ 一致 |
| X坐组大运流年值级刷新（_applyDLUpdates nz1-nz6） | changSheng(X干,新支) | 一致 | ✓ 一致 |
| 坐X组四柱区（sitRowMain） | **对角单值**：仅 X 柱列=p[X].zz（该柱自坐），其余列空；本质是自坐行拆列复制，信息量为零 | 坐年行六列=changSheng(年干/月干/日干/时干/大运干/流年干, 年支) | ❌ 缺陷，需重写 |

实测硬数字（新定义应显示值，现实现均只有单个对角值）：

- 坐年：冠带 衰 养 养｜养 墓（现仅年列「冠带」）
- 坐时：死 胎 帝旺 病｜帝旺 沐浴（现仅时列「病」）
- 坐胎：胎年养 胎元养 命宫冠带 身宫衰（现仅胎元列「养」）
- 坐身：胎年胎 胎元胎 命宫临官 身宫病（现仅身宫列「病」）
- 本盘年月日支同为戌（三戌同支），故坐年/坐月/坐日三行值相同——盘面特性，非口径问题

### 对重设计的约束

1. sitRowMain/sitRowSy 重写为「固定支遍历干」，参照支取 p[col].zhi（三垣区坐胎取胎元支）。
2. data-row-type 追加刷新 token，_applyDLUpdates 补四条 updates（需把四柱支传入 refs——现 _zuoRefs 只传参照干）。
3. main.js v0.43z 断言节需补坐X行值对拍（现断言只覆盖显隐与主坐值，坐X值从未被断言——这正是缺陷漏网的原因）。
4. CHANGELOG v0.43.0/v0.43.1 节中「坐X = X柱天干对自身地支」的表述需随修正改口径。
5. 修正应升 v0.43.2 走完整迭代闭环（构建→断言→实测→升版→发版）。
