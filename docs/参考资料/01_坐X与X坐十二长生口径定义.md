# 坐X 与 X坐 · 十二长生口径定义

> 来源：邦顺口述，2026-10-02
> 背景：v0.43.1 发版实测后，对「X坐/坐X」两组简分行的语义澄清

---

## 原文

年坐就是年干在每一个地支的十二长生。坐年就是每一个年干坐年支的十二长生，其它的如此类推。

## 口径解读（军师注，非原文）

- **X坐**（年坐/月坐/时坐/胎坐/命坐/身坐）：固定 **X 柱天干**为参照，对**每一个地支**（四柱区=年月日时+大运+流年支；三垣区=胎年/胎元/命宫/身宫支）求十二长生。
  - 年坐 = changSheng(年干, 各支)，一行多值。
- **坐X**（坐年/坐月/坐日/坐时/坐胎/坐命/坐身）：固定 **X 支**为参照，对**每一个天干**求十二长生。
  - 坐年 = changSheng(各柱干, 年支)：年柱列=年干坐年支、月柱列=月干坐年支、日柱列=日干坐年支、时柱列=时干坐年支（大运/流年列=大运干/流年干坐年支）。
  - 坐X 与 X坐 互为**转置对称**：一个固定干遍历支，一个固定支遍历干。
- 「每一个年干坐年支」按上下文读作「每一个（柱的）天干坐年支」——「年」字疑为口误，待邦顺裁决确认。
- 三垣区坐胎/坐命/坐身：固定胎元支/命宫支/身宫支，三垣四列（胎年/胎元/命宫/身宫）各列干坐该支。胎支取胎元支（胎年只是胎元的年干投影，主体是胎元）——此为建议口径，待裁决。
