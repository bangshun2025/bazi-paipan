### 代码改动

1. **CSS 由名单改全盘规则**（三产物同改）：删掉 v0.67.x 的 8 条 `tr[data-row-type=...]` 命中名单，改为 `.chart.ssh-on th, .chart.ssh-on td { text-align:left }`；非 `.rl` 行标格补 `padding-left:8px`，与四行左缘对齐。取消勾选即回落居中。
2. **藏气逐层分隔线**：`.ssh-cg-l + .ssh-cg-l` 加 `border-top:1px solid var(--c-line)` + `margin-top/padding-top:4px`（首层无线）；`.ssh-cg-ns` 由 `align-items:center` 改 `flex-start`，多组对应名左对齐成列；`.chart.ssh-on td > .ssh-cg-v { width:100% }` + `.ssh-cg-l { align-self:stretch }` 让分隔线撑满单元格宽度。
3. **对比卡例外**：`.cmp-card .ssh-cg-l + .ssh-cg-l` 撤掉分隔线与内外距。对比卡藏气行是固定高 `calc(4.8em + 11px)`，加线会把行撑高 9px/层，破坏已校准的卡片高度（门禁第 5 项会当场报红）。
4. **右侧运流区**：`render.js` `renderChart` 给 `.luck-col` 追加 `ssh-on` 类；`.luck-col.ssh-on .luck-row .cell` 与 `.luck-col.ssh-on .jq-col` 同步左对齐，避免左半个盘靠左、右半个盘还居中。
5. **main.js 断言 +6**：X17（表头 4 格 + 纳音/纳运/主坐/自坐/空亡/神煞 + 大运/流年列全部 `left`）、X18（藏气第 2/3 层有上边框、首层无）、X19（`.ssh-cg-ns` 为 `flex-start`）、X20（`.luck-col` 带 `ssh-on` 且单元格 `left`）、X21（`.jq-col` 为 `left`）、X22（未勾选时表头回 `center`、无 `ssh-on`、运流单元格回 `center`）。
