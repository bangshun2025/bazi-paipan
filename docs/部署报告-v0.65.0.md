## 本版变更
- `render.js`：删除 `sshGanRow` / `sshGanRowSy` / `sshGanCell`（天干行上方的独立组名行），
  新增 `sshGanVert(ganHtml, rs, groups)` —— 天干字在左（`.ssh-g-g`），组对应名以 `.ssh-g-ns`
  竖排堆叠于右侧，结构与藏气 `sshCgVert` 同构
- 四柱天干行（`ln1`）、大运/流年两列、三垣天干行（`tr.rg[data-sec="sanyuan"]`）全部改走 `sshGanVert`
- `_applyDLUpdates()` / `_mdlFillCell()` 天干同步改写，不再插入组名行
- 新增 `cellGanText(td)`：太极点点击只取天干字，避免把右侧组名读进干支（否则 `setTaiji('辛盟友')` 失效）
- `main.js`：新增 `pureCellText(cell)` 剥离组名块，改写所有读取干支 textContent 的断言
- `index.html` / `standalone-split.html`：`.ssh-g-v` / `.ssh-g-l` / `.ssh-g-g` / `.ssh-g-ns` / `.ssh-g-n`
  样式 + 四行 `text-align:left; padding-left:8px`
- 断言 +15：T06（天干格含组名块）、T08（首块=天干字）、T09（组名映射）、T12d（多组各出一条名）、
  T12e（顺序=勾选顺序）、T13/T14（大运流年列）、T15（清空后无组名块）、T17/T18/T19（三垣）、
  X08（组名块右于天干字）、X09（三行左对齐）
