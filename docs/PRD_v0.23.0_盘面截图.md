## 三、需求背景

**当前状态（v0.22.0）**：排盘结果渲染在 #output 区域（四柱盘式、三垣、大运、流年、宫位标签等），页面整体自然滚动（#output 无高度/溢出限制）。用户想把排盘结果发给学员或存档，只能手动截图——屏幕截不全长内容，需多次拼接。

**新需求**：邦顺在排盘页点「截图」，一键把 #output 区域**完整内容**（含滚动区外的部分）截为 PNG 长图并下载，用于发给学员讲解、存档、朋友圈展示。

**使用场景**：
1. 讲课：排好学员盘 → 截图发微信 → 学员看到完整盘面
2. 存档：报告资料留底（存手机相册 / 电脑文件夹）
3. 展示：盘面长图分享到朋友圈 / 群

## 四、方案概述

### 4.1 总体思路

**入口**：输入区按钮行新增「📷 截图」按钮（主操作「排 盘」之后）。**捕获方式**：将 #output 节点克隆到离屏容器（position:fixed; left:-9999px），对克隆体做 DOM→Canvas 渲染，生成完整高度 PNG（长图），触发浏览器下载。**所见即所得**：截图内容 = 当前屏幕上 #output 显示的内容（含隐私模式脱敏效果）。

### 4.2 技术方案决策点（架构师 ADR 细化）

**核心决策：DOM→PNG 的渲染引擎选择。** 项目约束为零构建、纯原生 JS。候选方案：

| 方案 | 描述 | 优势 | 劣势 | 结论 |
|------|------|------|------|------|
| A. html2canvas CDN 按需加载 | 首次点击截图时动态注入 script，加载后执行；加载失败给友好提示 | 成熟稳定、DOM 保真度高、长图（克隆离屏渲染）方案行业标准；构建流程零改动 | 依赖网络（首次点击需联网）；非官方库 | ✅ **推荐** |
| B. html2canvas 内联进 index.html | 把 minified 库直接写进单文件 | 离线可用、无 CDN 依赖 | 文件体积 +约 200KB（当前 735KB）；后续升级需手动替换 | 🟡 备选（若邦顺明确要离线可用） |
| C. 纯原生手写（SVG foreignObject 或自绘 Canvas） | 零第三方依赖 | 无网络/体积成本 | foreignObject 跨浏览器兼容性差（iOS Safari 字体/样式问题多）；自绘 Canvas 需双份维护渲染逻辑（渲染规则两套，必漂移） | ❌ 不推荐 |

**倾向**：方案 A。理由：本功能是低频工具型操作，非核心排盘路径，不值得为它膨胀单文件体积或引入高风险自绘方案；CDN 失败时给出「网络不可用，请重试」提示即可，不阻塞主流程。最终选型由架构师在 ADR 决策（含 CDN 地址、版本锁定、加载失败降级）。

### 4.3 截图范围定义

- **捕获对象**：#output 元素内的全部已渲染内容（person-info 标题行、盘式表格、三垣、大运、流年、宫位标签等）。
- **长图要求**：完整高度 = #output 实际内容高度（可能远超视口），输出 PNG 高度等于内容高度，不截断。
- **不含**：输入区（.input-section）、按钮行、档案弹窗等页面其他元素。
- **捕获时机**：#output 处于最终渲染态（排盘完成、宫位标签挂载完成）后才允许截图。

## 五、需求详述

### 5.1 按钮（index.html 输入区按钮行）

| 维度 | 要求 |
|------|------|
| 位置 | 输入区 `.input-row` 按钮行内，「排 盘」按钮**之后第一个位置**（截图是排盘结果的直接后续操作，紧跟主操作最顺） |
| 文案 | `📷 截图` |
| 样式 | 与「排 盘」同级 `.btn`；建议与「📋 档案」「🔒 隐私」一致的次按钮样式（paper 底 + 墨色字 + 边框），避免与主操作抢视觉权重 |
| id | `btnScreenshot` |
| 事件 | `onclick="APP.captureScreenshot()"`（与现有命名空间前缀规范一致） |

### 5.2 点击行为（main.js `APP.captureScreenshot`）

**流程**：

```
captureScreenshot():
  1. 检查 #output 是否已排盘（content 含 person-info 或等价标志；仍显示「输入出生时间，点击「排盘」」占位 = 未排盘）
     未排盘 → 提示「请先排盘」，return
  2. 防重入：若正在截图（busy 标志）→ return
  3. 按钮进入 busy 态：文案变「⏳ 截图中…」，disabled
  4. 确保截图引擎已加载（方案 A 为 CDN 动态加载，首次触发；加载失败 → 恢复按钮，提示「截图组件加载失败，请检查网络后重试」）
  5. 克隆 #output → 离屏容器（position:fixed; left:-9999px; top:0; z-index:-1），
     克隆体继承页面全部样式（克隆后仍在 document 内，CSS 天然生效），不做任何高度裁剪
  6. 渲染克隆体为 Canvas → toBlob / toDataURL 生成 PNG
  7. 生成下载文件名（见 §5.4），触发 a[download] 下载
  8. 清理：移除离屏容器、释放 canvas、恢复按钮文案「📷 截图」、解除 disabled
```

### 5.3 交互细节

| 场景 | 预期表现 |
|------|----------|
| 未排盘点击「截图」 | 轻量提示「请先排盘」（现有页面无 toast 组件，可用按钮旁瞬时提示或 alert，实现时取最简方案），不报错、不下载、无离屏残留 |
| 截图进行中 | 按钮显示「⏳ 截图中…」并禁用，防重复点击 |
| 截图完成 | 按钮恢复「📷 截图」；浏览器触发 PNG 下载 |
| 截图失败（引擎加载失败 / 渲染异常） | 按钮恢复；提示「截图失败，请重试」；console 记录错误；**不阻塞排盘主流程** |
| 大运/流年联动切换后截图 | 截的是**当前显示态**（所见即所得），含当前高亮/选中状态 |
| 简分级别（L0-L3）切换后截图 | 截当前级别显示的盘面内容，层级逻辑不因截图而改变 |
| 双胞胎 / 龙凤胎排盘 | 同样支持，截当前对比视图完整内容 |

### 5.4 下载文件名（隐私联动）

**文件名格式**：`八字排盘_<显示名>_<YYYYMMDD>.png`

- **显示名来源**：与 v0.19.0 隐私模式统一——`getDisplayName` 的当前显示名（隐私开启：艺名 → 小名 → 匿名降级；隐私关闭：`nickname / name` 现状格式）。**文件名绝不直接读 `data.name`（真名）**。
- **隐私铁律**：隐私开启时，文件名中的显示名必须与盘面显示一致（脱敏），截图中不含真名（显示层已脱敏，截图自然继承），文件名不泄漏真名。
- **字符清洗**：显示名中的 `/`、空格等对文件名不友好的字符需清洗（如替换为 `-`）；显示名为空时用「匿名」兜底。
- **日期**：截图当天日期（本地时间）。

### 5.5 三文件同步（承接遗留项 L1）

截图按钮及关联 CSS 需同步三个 HTML 文件：

| 文件 | 角色 | 要求 |

| standalone-split.html | 主产物（开发验证入口） | 同步按钮 + CSS |
| standalone.html | 内联回退版 | 同步按钮 + CSS + 截图 JS 逻辑 |
| index.html | Clacky 扩展内联版 | 同步按钮 + CSS + 截图 JS 逻辑 |

- 截图 JS 逻辑落 main.js（`APP.captureScreenshot`，保持 6 模块结构不变、不新增模块），两个内联版由人工同步（沿袭现有模式，`build_modules.py` 是拆分工具，不依赖它回写）。
- `scripts/check-release.sh` 的「HTML 关键 id」检查点加入 `btnScreenshot`（由编程师在实施时确认检查清单覆盖）。

### 5.6 隐私模式表现（决策结论）

| 决策 | 结论 | 理由 |
|------|------|------|
| 隐私开启时截图是否打码 | **所见即所得**：截的就是屏幕上显示的盘面（已脱敏），不做截图时二次打码 | v0.19.0 已保证显示层全脱敏（person-info、档案列表等所有显示点走 `getDisplayName`），截图是显示层的忠实拷贝，无需额外加工 |
| 隐私关闭时截图 | 正常截取（含真名显示态） | 用户自己控制开关；邦顺发给学员前会开隐私，这是既有使用习惯（默认开启） |
| 文件名 | 一律用当前显示名（隐私开启即脱敏名） | 文件名是「发出物」的一部分，与盘面内容同步脱敏；此条也补齐 L2 隐私断言缺口 |
| 宫位标签 | 随盘面照实截取 | 宫位标签是盘面内容的一部分（命宫/身宫等），不涉姓名，无脱敏问题 |

## 九、风险评估

### 9.1 渲染引擎对 CSS 变量 / 字体的兼容性

**风险**：项目样式大量使用 CSS 变量（`var(--c-ink)` 等）与 `--font-display` 自定义字体族，html2canvas 对 CSS 变量支持良好，但对个别属性（如某些 webkit 前缀阴影、渐变）可能有渲染差异。

**缓解**：克隆体保留在 document 内（CSS 自然生效）；测试师按 AM01/AM02 人工比对截图与页面观感；若个别样式丢失，实施时对该样式降级处理（截图引擎分支适配），不反向改主样式。

### 9.2 CDN 加载失败（方案 A 特有）

**风险**：首次截图需联网拉取引擎，离线/弱网失败。

**缓解**：明确失败提示 + 按钮恢复；引擎加载成功一次后浏览器缓存，二次使用不再依赖网络；若邦顺反馈离线场景高频，再评估方案 B（内联）。

### 9.3 大图内存与浏览器上限

**风险**：极长盘面（如大运 8 柱 + 流年多行全展开）canvas 尺寸过大，个别移动浏览器有 canvas 面积上限。

**缓解**：实测本项目盘面高度在数千像素级，远低于上限；如未来流年区极度扩展，实施时可在渲染引擎处设置高度上限分片合成（ADR 备注，本版本不实现）。

### 9.4 隐私泄漏面

**风险**：实现时若图省事直接用 `data.name` 拼文件名，隐私模式下文件名泄漏真名——与 v0.19.0 铁律冲突。

**缓解**：PRD §5.4 已明确文件名必须走 `getDisplayName`；T03/T04 断言把降级链固化为自动化回归；测试师 AC09-AC12 专项覆盖。

### 9.5 三文件同步遗漏（遗留项 L1 复发）

**风险**：只改 standalone-split.html 而漏同步两个内联版，双环境回归才暴露。

**缓解**：PRD §5.5 列明同步要求；`check-release.sh` 加 `btnScreenshot` 检查点；发布清单走既有流程。

## 十、给架构师的 ADR 输入

1. **渲染引擎选型**：§4.2 方案 A/B/C 决策（倾向 A：html2canvas CDN 按需加载），含 CDN 地址、版本锁定策略、加载失败降级路径。
2. **克隆渲染细节**：离屏容器参数（position/left/top/z-index）、克隆后是否需修正 body 级继承样式、canvas 缩放系数（devicePixelRatio 适配，保证 Retina 屏文字清晰）。
3. **下载实现**：`toBlob` vs `toDataURL`（大图 toBlob 更省内存）、`a[download]` 兼容处理。
4. **未排盘判定标准**：#output 内容判定用「含 person-info」还是引入显式状态标志（若判定标志与现有代码耦合，需给出最小侵入方案）。
5. **断言挂载点**：文件名纯函数放 main.js 哪个命名空间（建议 `APP.buildScreenshotFilename`），与 ?test=1 断言框架对接方式。
