### TC-10 · 龙凤胎卡片初始状态 ⚠️

**操作**：切换到龙凤胎模式 → 点击「排盘」→ 观察 L0 默认状态

**预期**：两张卡片均为 L0，仅星运+自坐可见

**结果**：❌ **FAIL**

- **现象**：首次加载龙凤胎排盘后，按钮显示「简」（L0），但老大和老二卡片的所有扩展行（纳音/纳运/空亡/神煞）全部可见
- **根因分析**：龙凤胎卡片的 `<table>` 初始 HTML 模板未带 `level-0` class（或旧代码中未添加），导致 CSS 隐藏规则不生效
- **修复后表现**：点击按钮触发 `toggleLevel()` 后，函数主动添加 `level-0` class，后续 L0 状态正常
- **严重程度**：中 — 首次加载体验不符预期，但功能本身可用（点一次按钮即修复）
- **修复建议**：检查 `renderTwinCardsHtml()` / `renderLongFengCardsHtml()` 中 `<table class="chart">` 是否已改为 `<table class="chart level-0">`
