## 0. 本次变更的性质（先说清测什么）

用户澄清：**「分三组」= 60 个甲子在一屏内看得完、操作得完（免滚动）**，不是「纵向 3 段 + 分组标题」。

⇒ 被改写的契约：**布局与分组呈现**。
⇒ 不变的契约：**搜索匹配、筛选机制（`hidden`）、持久化、草稿采集（P0 红线）、数据层**。

本草案只覆盖「被改写」的部分；「不变」的部分沿用 v1.0（HP1–HP5、T05/T10/T11）。

### 0.2 筛选态栏位缺陷（编程师实测 → Leader 终裁 → r7 AC25/T15）

**缺陷**：r6 FR3.4 推荐的 `.xy-table tbody{display:grid;grid-auto-flow:column;...}` 在**筛选态**下失效 —— `display:none` 的行**不是 grid item**，被 auto-placement **跳过** ⇒ 筛选后命中行**全塌到栏 1**。

**假绿陷阱**：此时按 `[data-xy-group]` 计数可能仍显示 **2/2/2**（DOM 属性未变）⇒ **只数 `data-xy-group` 会判过关**，掩盖真实几何错位。

**Leader 终裁（断言策略，已落 r7 FR3.4.3 / D20）**：
1. 断言一律锁 **钩子 / 行为 / 几何**；
2. **禁止断言 computed `grid-auto-flow` / `grid-template-*` 的字面值**（锁死实现；且 r6 字面写法本身不满足 FR3.8 空栏占位）；
3. **不需要** `nth-child` 式定位断言；
4. **筛选态栏位正确性 = 几何判定**（见 §3.4 F1），**严禁仅凭计数判定**。

**PRD r7 落地（已冻结，md5 `2c82f007f4983ce031c8447b8b433d7a`，566 行）**：**AC25 / T15**（追加，不重排 T01–T14）；**FR3.4.3**（断言边界，禁锁 CSS 字面值）；**D19**（CSS 必须「按组钉列」）/ **D20**（禁锁 CSS 字面值）。

**编程师实现（已横向确认）**：`@media(min-width:1280px)` 内 `grid-auto-flow: row dense` + `grid-template-columns:repeat(3,minmax(0,1fr))` + **每行 `tr[data-xy-group="N"]{grid-column:N}`（CSS 规则，非内联）**，纯 CSS、单 `tbody`；`<1280px` 为单栏纵向（`grid-auto-flow:row` + `grid-template-columns:minmax(0,1fr)`）。

## 3. 断言规格

### 3.1 三栏几何（标称值口径，不做 pixel-perfect）

| 编号 | 断言 | 期望 / 容差 |
|---|---|---|
| **G1** | 栏头数量 | `document.querySelectorAll('.xy-group-title').length === 3`；三个均 `display !== 'none'` |
| **G2** | **三栏同排** | 三个 K4 栏头的 `getBoundingClientRect().top` 两两之差 ≤ **8px**（AC21 容差） |
| **G3** | 横向次序 | 栏头 `left` 依次递增，相邻间隔 > 0 |
| **G4** | 栏宽 | 各栏宽 > 0（等宽由 `minmax(0,1fr)` 保证，**不写死像素**） |
| **G5** | 不横向溢出 | 栏区 `right ≤ body.getBoundingClientRect().right + 1px` |
| **G6** | 栏归属计数 | 按 `data-xy-group` 计 `tr[data-gz]` = **20 / 20 / 20**，与 G1 一一对应 |
| **G7** | **弹层宽度** | `Math.abs(modalW - Math.min(0.9*innerWidth, 1200)) <= 8`（AC22）。⚠️ **禁止**断「≥85% 视口」：1440 屏下 `min(90vw,1200)=1200` 只占 83.3%，必假红 |
| **G8** | **可见行三栏归位（r7 实测基线）** | 全显态（60 行）：可见行 `getBoundingClientRect().left` 呈 **恰好 3 个不同值**、各 **20** 行（真实应用实测 **175 / 567.7 / 960.3**，栏宽 376.7，与三个栏头 `left` 同 x）。**仅 ≥1280px** |

- **取样前置**：`XINGYAO.openSettings()` 且 `#xySettingsOverlay` 含 `.show`（未开弹层几何全为 0）。
- **禁止**：写死像素宽度、断言 `1fr` 具体值、用 `offsetParent`/`getBoundingClientRect` 判**可见性**。
- **禁止断言绝对 `y`（ADR v1.6 §15.4）**：`.xy-settings-modal` 高度自适应命中数 + 弹层垂直居中 ⇒ **绝对 `y` 随命中数变化**（实测栏头 `top`：全显 **144** → 搜「甲子」**376.8** → 搜「斗数」**408.3**）。**几何断言只能用水平量（`left`/`width`/`right`）**；垂直方向只允许**相对量**（如栏头两两 `top` 之差 ≤8px）。

### 3.2 免滚动（条件化 + 取样时机 + 假绿陷阱）

| 编号 | 断言 | 期望 / 条件 |
|---|---|---|
| **R0** | **前置守卫（防假绿）** | `#xySettingsOverlay.classList.contains('show') === true` **且** `body.clientHeight > 0` |
| **R1** | **仅空查询态断** | 断言前 `XINGYAO.filterRows('')`，可见行 = 60 |
| **R2** | **免滚动量** | `.xy-settings-body` 的 `scrollHeight - clientHeight ≤ 2px`（r6 定稿阈值） |
| **R3** | **绑三视口基线** | 1440×900（主）、**1280×800**、**1600×1000** **均须成立**；<1280px 不适用（走 §3.3） |
| **R4** | **取样时机** | `await document.fonts.ready` 之后（或 rAF×2）再取样 |

> **致命陷阱（必须写进 ADR v1.4 / 断言，r6 E23）**：`display:none`（弹层未打开）时 `scrollHeight` 与 `clientHeight` **同为 0**，`0 ≤ 0` **恒真** ⇒ 不开弹层直接断**必然假绿**。R0 就是这条的守卫。
> **反例**：`if (body.scrollHeight <= body.clientHeight) pass;`（无 R0/R1/R3）—— 三种情况下都会假绿。

> **C8 口径留痕（测试侧 → Leader 裁定）**：
> - 我初判给架构师的是 **不采纳为阻断断言、改观测项**，依据是 **PRD r7 FR3.4.1（:276）**「4 列名作为**通栏图例**呈现，与各栏内字段**不做逐列像素对齐**……**不阻断本版验收**」，以及 **FR3.4.3（:273）** 以枚举法限定可断言几何面（**不含** `th[i]` ↔ 第 i 列）。**对架构师依据句的勘误**：其「r7 FR3.4.1 只要求 `thead th`=4、**未规定几何**」不完整 —— :276 确实规定了几何语义。
> - **Leader 裁定：采纳**（授权 ADR 层新增契约覆盖该已知取舍）。**本行按 Leader 最终裁定落地为阻断断言**；上段留痕供追溯。**未使用 PRD 的 T 编号**（PRD r7 终冻、不升 r8），本项只进测试规格 + ADR §15.3/§15.6 契约。
