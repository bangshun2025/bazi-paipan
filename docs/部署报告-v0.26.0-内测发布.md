1. 本发布已落本地扩展容器 `bazi-paipan`（`~/.clacky/ext/local/bazi-paipan`），Clacky 侧边栏「八字排盘」入口即指向此容器。

5. 等待用户 L4 手动验收后再决策正式版（GitHub Pages）发布。

## 5. 备注

- **ext.yml 版本格式**：当前 `clacky ext verify` schema 要求 version 为**纯数字三段**（如 `0.26.0`），带 `v` 前缀会报 `schema.invalid_version`。故 `ext.yml` 写 `0.26.0`，对外版本名 / CHANGELOG / SYSTEM.md / 源码头注释仍用 `v0.26.0` 展示（与本机其它扩展如 ziwei-paipan `0.5.0` 格式一致）。
- **verify 遗留 ERR（非本次对象）**：`bazi-paipan-test`（`v0.25.0`）、`qimen-paipan`（`v0.9.6`）、`qimen-paipan-test` 三个**独立容器**仍因历史 `v` 前缀 ext.yml 报同一 schema ERR，属历史遗留、不在本次发布范围（本次仅主仓库 `bazi-paipan`）。如需要可另行安排统一清理。
- 主仓库 git 工作树含多份未提交改动（render.js/main.js/三 HTML/scripts/check-release.sh 等来自实现阶段；CHANGELOG/SYSTEM.md/ext.yml 为本次发布动作），未执行 git commit —— 内测发布不 push，正式版发布时统一提交。
