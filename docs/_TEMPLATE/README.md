# _TEMPLATE — 新功能开发模板

> 用法：复制整个 `_TEMPLATE/` 目录到 `../<功能名>/`，按模板填写各文件。
> 每个文件只写本次功能相关内容，不要复制模板说明文字。

## 目录结构

```
<功能名>/
├── PRD.md          ← 产品经理：需求定义
├── ADR.md          ← 架构师：技术决策
├── 变更记录.md      ← 前端开发：代码变更详情
├── QA.md           ← 测试工程师：测试计划与报告
├── 流程记录.md      ← 流程师：关键决策时间线
└── 发布报告.md      ← 发布工程师：版本发布摘要
```

## 注意事项

1. **PRD 先写**：写清楚 AC（验收条件），后续角色都以此为准
2. **ADR 紧随**：决定技术方案，标注影响范围和备选方案
3. **变更记录按实写**：改了哪些代码段、行数变化，不要估计
4. **QA 在实现前写**：知道要测什么再动手，而不是做完再想
5. **发布报告 = CHANGELOG 条目 + 检查清单打勾结果**
