## 一、本版内容：十干对应

### 需求原文

> 再加上一个功能，十干对应功能，请参照完全参照十神功能与宫位功能。具体的对应放在哪里？放在十神对应前面，并用竖线分隔与十神词。比如
>
> ```
> 甲 怜悯  ｜  机会
> 戌
> 戊 才 诚信 ｜ 技术
> ```

### 落地形态

| 位置 | 渲染顺序 |
|---|---|
| 天干单元 | 天干 → 十干对应名 → ｜ → 十神组对应名 |
| 藏气层 | 藏干 → 十神 → 十干对应名 → ｜ → 十神组对应名 |

竖线是十神组对应名块的左边框（`.gy-sep`），只在十干对应有值时才出现；没有配置的天干不占位、不留空。

### 与十神组同构的部分

| 项 | 十神组（既有） | 十干对应（本版） |
|---|---|---|
| 数据键 | `bz_shishen_groups_v1` | `bz_gan_groups_v1` |
| 勾选键 | `bz_shishen_selected_v1` | `bz_gan_selected_v1` |
| 面板按钮 | 十神 N ▾ | 十干 N ▾（排在十神左侧） |
| 全选 / 清空 | 有 | 有 |
| ⚙ 设置弹窗 | 十神设置 | 十干设置（十天干各一个输入框，组可增删） |
| 组数量 | 多组 | 多组 |

三处互斥逻辑已接入：打开十干面板会关掉十神/宫位面板，反之亦然。

### 默认配置

预置一组「德性」：**甲 = 怜悯**、**戊 = 诚信**，其余八干（乙丙丁己庚辛壬癸）留空。空值不渲染。

十干组默认**不勾选**，老用户打开页面看到的是与 v0.69.0 完全一致的排版；点「十干」勾选后才出现对应名。

> 其余八个干（乙丙丁己庚辛壬癸）的词，可在「⚙ 十干设置」里自行填写，或给一套词预置进默认组。
