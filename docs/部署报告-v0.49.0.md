## 2. 新增内容

### 转换太极点（本版主打）

- 单盘主表点原局四柱天干或藏气行藏干，弹菜单「设为新太极点」；确认后 `algorithm.shiShen` 内部把日干劫持为所选天干（一处改动全局生效）：主星行、藏气十神、大运列、流年列、地支主气全部换中心重算。
- 被选天干套五行色圆圈（`.taiji-ring` 继承 wood/fire/earth/metal/water 配色）；主星行该柱标注「年主/月主/日主/时主」，藏干标「主」。
- 再点当前太极点显示「恢复日主太极点」，一键回基线；点击页面其他处自动关菜单。
- 仅单盘主表生效（`inMainChart` 排除双胞胎卡/对比卡/运流卡），双卡对比互不干扰。
- 修弹窗遗留监听隐患：document 的 once 关闭监听残留会导致下一次开菜单闪现即消失，天干/藏干两处 handler 补 stopPropagation 根治。

### 双胞胎卡分析记录版（48ca065，随本次一并上线）

- 双胞胎排盘 tabs 行尾新增「分析记录」入口：面板居两卡与共享运流区之间（记录占主位、运流顺延），textarea 写入即自动保存，1.5s「已保存 HH:MM:SS」提示；重渲染后开关态与稿子保留。

- 修复 tabs 行「流月/流月日」勾选条上浮错位。
