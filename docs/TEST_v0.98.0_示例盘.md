## 1. 需求

1. 造出来的示例盘**要存档**，但不进正式档案 —— 存进「示例盘」。
2. 描述解析要「完全听懂」自然说法。

## 2. 示例盘（独立存档）

| 项 | 实现 |
|---|---|
| 存储 | `localStorage['bz_gen_examples']`，独立于 `bz_archives_v2`（实测生成前后档案条数恒为 17） |
| 写入 | 造盘成功后自动写入，无需手动保存 |
| 去重 | 同「特征 + 四柱 + 性别」视为同一张，复用原 id 并置顶 |
| 上限 | 60 条，超出裁掉最旧 |
| 条目字段 | 输入原话、特征标签、性别、年月日时、扫描时刻数、证据、四柱、存入时间 |
| 重开 | 用 `ALGO.paipan` 现算整盘（大运/起运齐全），不存整盘快照，避免版本升级后数据漂移 |
| 删除/清空 | 单条 ✕；清空需确认，明示「不影响档案」 |
| 转存档案 | 横幅上的「⭐ 转存档案」走 `ARCHIVE.saveArchive()`，此时才进档案 |
| 入口 | 顶部「📚 示例盘」带条数角标；横幅内也有一个 |

## 3. 解析能力（能听懂的说法）

归一化：全角转半角、常见繁体转简体（兩/殺/時/傷/財/沖/會…）、去空白标点。

| 能力 | 例子 |
|---|---|
| 柱位限定 | 月柱七杀、时干正官、时支寅透甲丙戊 |
| 精确计数 | 七杀正好两个（其余默认 ≥N） |
| 十神组 | 官杀透两干、财星/印星/比劫/食伤透两头 |
| 点名干支 | 寅透甲丙戊、天干见甲丙、地支见子辰 |
| 五行认局 | 三合水局 → 申子辰；巳午未三会 → 火方 |
| 多特征组合 | 申子辰三合 + 官杀混杂（顿号、逗号、且、和 均可） |
| 否定 | 官杀混杂且不冲 |
| 性别 | 坤造 / 女命 / 乾造 / 男命 |
| 认不出 | 不硬猜，给 3 条「是不是想说」可直接点选 |

诚实边界：这是规则 + 词表 + 组合语法，覆盖主流术语与口语变体；没把握时**明说没认出并给候选**，绝不给一张不对的盘。真要「任意中文都懂」得上模型，属于另一个量级的工程。

## 6. 关键口径

- **示例盘 ≠ 档案**：造盘路径完全不碰 `autoSaveArchive` / `saveLastChart`；要入档只有两条路——点横幅「⭐ 转存档案」，或按原样点「排 盘」。
- **重开是现算不是快照**：只存年月日时与证据，重开时走当前引擎的 `paipan`；引擎升级后旧示例仍然按新规则呈现。
- **组合特征走同一条扫描**：`parse` 把多句切成 `and`，`compile` 生成合并判据；命中后再用完整 `paipan` 复核一次。
