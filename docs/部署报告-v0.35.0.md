## 2. 修复内容

人元司令排错：1982-10-18 卯时（寒露后第 10 日）应得丁司令，线上误排辛。

根因：`daysAfter` 为 0 起算的完整天数（节后第 N 日 ⇔ N-1），`algorithm.js`
`renYuanSiLing()` 段边界判断用 `daysAfter <= maxDay`，令 REN_YUAN 表每段司令
多占 1 日，下一段的第一天被上一段吞掉。表注释口径（戌月：辛 1-9 日／丁
10-12 日／戊 13-30 日）本身正确，是判断写错。

- 边界 `<=` 改 `<`，三端同步（`index.html` / `standalone.html` 经 sync-module-inline 内联一致）
- `?test=1` 新增 6 条 SL 边界断言（含锚点盘 1982-10-18 卯时 → 丁）
