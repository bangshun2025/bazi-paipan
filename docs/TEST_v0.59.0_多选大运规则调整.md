# TEST v0.59.0 — 多选大运规则调整

日期：2026-10-18 ｜ 前版：v0.58.0

## 需求

1. 最多只能选两个大运（v0.57.0 已有）
2. 流年只能是所选大运底下的流年（**新增归属限制**）
3. 两大运分别放置在时柱右边、身宫右边（v0.57.0 已有）
4. 时柱后面的大运的时间要在身宫后面的大运之前（**新增显示序规则**）
5. 流年按在该大运下从早到晚的次序排（大运区间不重叠 ⇒ 全局升序即分组序，随②自然满足）
