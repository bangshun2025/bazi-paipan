## 2. 新增内容

**① ⛶ 专注按钮**

- 对比页工具栏右上角（「关 闭」旁）新增「⛶ 专注」，进入后收起管理类子项（标题/计数/档案/清空/关闭），缩放/布局/简分/宫位/名字开关全部保留；再点（按钮变「⛶ 退出专注」）全部恢复。按钮常驻不被收起，active 态墨色高亮。

**② 工具与五区勾选并一行**

- 进入专注时五区勾选栏（运流项/藏气区/三垣区/运流区/节气区）DOM 由独立行移入 `.cmp-toolbar`（`_cmpApplyFocus` 按 `btnCmpFocus` 锚位插入，CSS 去其自身 border/padding）——专注态只剩工具栏一行（实测 50px），整屏高度让给盘面轨道；退出时勾选栏按原锚位放回 `.cmp-dialog` 独立行。

**③ 自动收名字条**

- 进入专注时名字条若展开则自动收起（`bz_cmp_bar` 落 '0'），退出专注**不**自动恢复（设计如此，点「名字」随时展开）；专注中名字开关可正常开合。

**④ 持久化 + 挂钩**

- 状态存 `bz_cmp_focus`（'1'/'0'），`cmpOpen` 时重放（关开对比页、刷新页面均保持）；模块装载与打开对比页时同步按钮文案/类名与勾选栏位置。

**⑤ 测试**
