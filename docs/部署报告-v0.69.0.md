## 一、本版内容

### 1. 档案防丢改造（邦顺主诉求）

病根：`archive.js` 的 `saveArchives()` 是整表覆盖写，且列表渲染每次都「按名排序 → 整表回写」。多标签页各持旧副本，后写覆盖先写，历史上丢档由此而来。

修法：

| 项 | 做法 |
|---|---|
| 写盘 | `writeArchives()/saveTrash()` 无条件并集合并，本地在前、盘上独有项追加末尾 |
| 冲突 | 同键按 `updatedAt` 严格较新才替换，平局保留本地（改名不回退旧值） |
| 删除 | 写墓碑 `bz_archives_tomb`，旧副本回写不复活已删档案 |
| 跨页 | 监听 `storage`，另一页写盘后同步基线并重渲染面板 |
| 配额 | 写盘失败给提示，60 秒节流，不再静默吞掉 |
| 备份 | 超 7 天未导出显示琥珀横幅，点击即导出 |

### 2. 新历 ↔ 农历切换自动换算

- `algorithm.js` 新增 `solarToLunar()`（查表法），与既有 `lunarToSolar()` 互逆。
- `toggleCalendar(type, convert)` 切换前取当前表单日期换算再回填，闰月一并带过。
- 载入历史档案走不换算路径，档案里存的日期原样保留。
