## 一、本版内容

**需求**：运流区调整到下方时，运流区在左边，流月面板在右上方，流日面板在右下方。

v0.71.0 下移后，流月、流日还堆在运流表底下——整块被拉成 1302×1105，视线得往下扫很久才见到流日。本版把它拆成两列。

**触发条件**：`.body-cols.luck-moved` + `.luck-col` 内有可见的 `.flow-panel`（`:has(.flow-panel:not([hidden]))`）。三种情况都不命中：未勾流月、未下移（没勾十神/十干）、分析记录模式。

**实现**（三产物同步，插在 `luck-moved` 规则之后）：

```css
@media (min-width:1280px) {
  .body-cols.luck-moved .luck-col:has(.flow-panel:not([hidden])) { display:grid; grid-template-columns:max-content minmax(0,1fr); column-gap:18px; align-items:start; }
  .body-cols.luck-moved .luck-col:has(.flow-panel:not([hidden])) > .flow-panel { grid-column:2; grid-row:1 / span 99; min-width:0; }
  .body-cols.luck-moved .luck-col:has(.flow-panel:not([hidden])) .flow-table { min-width:0; }
}
```

三处要点：

1. **必须放开 `.flow-table { min-width:520px }`**。左列吃掉 818px 后右列只剩 466px，不放开就撑出 56px 横向滚动（实测 VAR-A：overflow 56）。
2. **`grid-row: 1 / span 99`**，不是 `2 / span 99`。写 2 会让 auto-placement 把 `.luck-section` 塞进第 1 行第 2 列，运流表跑到右上角去（实测 R2：luckSection x=791 串位）。
3. **贴底方案弃用**：给 flow-panel 加 `align-self:stretch` + 流日 `margin-top:auto`，grid 行区域被拉到 1042px（比左列 741px 还高），整块反而更长。改用紧凑排列，流日紧接流月下方。
