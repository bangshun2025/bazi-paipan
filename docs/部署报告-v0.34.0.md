## 2. 修复内容

点档案行「排盘」按钮不排盘，必须关弹窗回主界面再点一次。

根因：`archive.js` 的 `setFormData(d)` 在 `prov` 分支裸调用 `onProvChange()` /
`onCityChange()`（定义在 `main.js` 的 IIFE 内，仅经 `window.APP.*` 暴露），
本模块内抛 `ReferenceError`，中断 `loadFromArchive()` 后续的
`closeArchivePanel()` 与 `APP.doPaipan()`。

- 地址回填改走 `APP.onProvChange()` / `APP.onCityChange()`
- 去掉两级 `setTimeout(..., 50)`，改同步回写（真太阳时不再漏算市/区县）
- 新增 `hasOption()`：下拉框无该选项时保持原值
