## 一、功能描述

在八字排盘表中新增 **「纳运」** 行，展示每柱**纳音五行在月令的十二长生状态**。

### 1.1 背景

排盘表目前已展示每柱的纳音（如壬戌→大海水），但纳音本身的旺衰（在月令处于长生/帝旺/死/绝等哪个阶段）尚未呈现。十二长生是判断纳音力量强弱的核心维度，新增纳运行可让用户一眼看清各柱纳音的时令状态。

### 1.2 核心逻辑

```
纳运值 = 十二长生(纳音五行, 月令地支)
```

1. 取该柱的纳音（从已有 NAYIN 字典获取，如「壬戌」→「大海水」）
2. 将纳音映射为五行（「大海水」→「水」）
3. 取月柱地支作为参照点（月令）
4. 查五行十二长生表，得出该纳音五行在月令的十二长生状态（如「水」在「子」月→「帝旺」）

### 1.3 示例

| 柱 | 干支 | 纳音 | 纳音五行 | 月令(假设) | 纳运 |
|----|------|------|----------|-----------|------|
| 年 | 壬戌 | 大海水 | 水 | 子 | 帝旺 |
| 月 | 甲子 | 海中金 | 金 | 子 | 死 |
| 日 | 丙寅 | 炉中火 | 火 | 子 | 胎 |
| 时 | 戊辰 | 大林木 | 木 | 子 | 沐浴 |

## 二、验收标准

### 2.1 功能验收

| 编号 | 验收项 | 标准 |
|------|--------|------|
| F1 | 七柱覆盖 | 年、月、日、时、胎元、命宫、身宫七柱均显示纳运值 |
| F2 | 值正确性 | 每柱纳运 = 该柱纳音五行在月令的十二长生状态，与十二长生表一致 |
| F3 | 月柱纳运 | 月柱自身的纳运 = 纳音五行在自身地支的十二长生（月令即自身地支） |
| F4 | 胎元/命宫/身宫 | 若无地支则纳运显示为空（如天干胎元），不做兜底填充 |

### 2.2 UI 验收

| 编号 | 验收项 | 标准 |
|------|--------|------|
| U1 | 位置 | 纳运行位于「自坐」行下方（即自坐行 → 纳运行 → 空亡行） |
| U2 | 行名 | 行头显示「纳运」 |
| U3 | 「简」按钮 | 点击「简」后，纳运行随其他详细信息行一起隐藏 |
| U4 | 「详」按钮 | 点击「详」后，纳运行随其他详细信息行一起显示 |
| U5 | 样式 | 纳运行风格与排盘表其他行一致（字体、颜色、对齐） |
| U6 | 空值处理 | 无法计算纳运的列（如无纳音或无月令），显示空或「—」 |

### 2.3 边界情况

| 编号 | 场景 | 预期行为 |
|------|------|----------|
| B1 | 纳音五行无法映射 | 纳运显示空，不崩溃 |
| B2 | 月令地支不存在 | 纳运全部显示空，不崩溃 |
| B3 | 四柱不全（如缺少时柱） | 有干支的柱正常计算，缺柱不显示 |
| B4 | 排盘表尚未渲染 | 不因纳运行的存在而报错 |

### 2.4 回归验证

纳运行的新增不应影响排盘表现有功能：
- 天干/地支/本中余气/纳音/星运/自坐/空亡/神煞 各行值不变
- 「简/详」切换逻辑不破坏
- 打印/导出不受影响

## 三、技术要点

### 3.1 纳音→五行映射表

需新增映射常量，从纳音名称提取五行。完整的 30 纳音映射：

```
金：海中金、剑锋金、白蜡金、沙中金、金箔金、钗钏金
水：涧下水、大溪水、长流水、天河水、井泉水、大海水
木：桑柘木、松柏木、大林木、杨柳木、石榴木、平地木
火：炉中火、山头火、霹雳火、山下火、覆灯火、天上火
土：路旁土、城头土、屋上土、壁上土、大驿土、沙中土
```

**实现建议**：根据纳音名称末字（金/水/木/火/土）判定五行，无需维护完整映射表，性能更好且不易出错。

### 3.2 十二长生查询表

基于用户提供的五行十二长生表构建查询结构：

```
五行 → { 地支 → 长生阶段 }

木：亥→长生 子→沐浴 丑→冠带 寅→临官 卯→帝旺 辰→衰 巳→病 午→死 未→墓 申→绝 酉→胎 戌→养
火：寅→长生 卯→沐浴 辰→冠带 巳→临官 午→帝旺 未→衰 申→病 酉→死 戌→墓 亥→绝 子→胎 丑→养
土：申→长生 酉→沐浴 戌→冠带 亥→临官 子→帝旺 丑→衰 寅→病 卯→死 辰→墓 巳→绝 午→胎 未→养
金：巳→长生 午→沐浴 未→冠带 申→临官 酉→帝旺 戌→衰 亥→病 子→死 丑→墓 寅→绝 卯→胎 辰→养
水：申→长生 酉→沐浴 戌→冠带 亥→临官 子→帝旺 丑→衰 寅→病 卯→死 辰→墓 巳→绝 午→胎 未→养
```

注意：土与水同源（长生在申），但查表逻辑需独立处理，不可直接复用。

### 3.3 计算流程

```
function getNaYun(pillarGanZhi, yueLingDiZhi):
    if pillarGanZhi 为空 or yueLingDiZhi 为空:
        return null
    
    naYin = NAYIN[pillarGanZhi]         // 已有字典：如 壬戌→大海水
    if naYin 为空:
        return null
    
    wuXing = naYin末字                    // 大海水→水
    changSheng = CHANG_SHENG[wuXing][yueLingDiZhi]  // 水+子→帝旺
    return changSheng
```

### 3.4 UI 插入位置

排盘表行序（现有 → 新增后）：

```
主星
天干
地支
本气 / 中气 / 余气
纳音
星运
自坐
纳运        ← 新增
空亡

```

「简」模式隐藏行：本气/中气/余气/纳音/星运/自坐/**纳运**/空亡/神煞（纳运加入隐藏白名单）。

### 3.5 实现注意事项

1. **代码位置**：在 `standalone.html` 中找到自坐行渲染逻辑，在其后插入纳运行渲染
2. **数据预计算**：在排盘数据生成阶段一次性计算好七柱的纳运值，而非在渲染时计算
3. **月令获取**：月令地支 = 月柱的地支（如甲子→子），在排盘数据中可直接取用
4. **性能**：纳运计算为纯查表操作，O(1)复杂度，无性能影响
5. **兼容性**：不改变现有数据结构的外层接口，纳运作为现有数据对象的扩展字段
