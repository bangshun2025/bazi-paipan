## 2. 新增内容

- **上下留白加大**：`.rec-text` 上下内边距 10px→18px，最小高 320px→360px。
- **随内容自动增高**：render.js 新增 `recAutogrow()`——textarea 装载草稿与每次 input 时 `height=auto → scrollHeight`，内容增多面板随之长高、清空回落到最小高；`resize:vertical`→`none`、加 `overflow:hidden`（自动增高接管，去掉手动拖动）。
- **边界修复**：`toggleRecMode` 打开面板瞬间补一次 autogrow。修复场景：长草稿在面板 `display:none` 时装载，`scrollHeight=0` 导致打开后高度被压到最小高（360px）且无滚动条，需再敲一键才恢复；补算后打开即按真实内容撑高。
- **断言**：分析记录区段新增 REC T07×5（上下内边距 18px／resize none／初始高度自适应不塌底／内容增多变高／清空回落不塌底）。
