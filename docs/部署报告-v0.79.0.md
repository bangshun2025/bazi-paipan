# 部署报告 · v0.79.0（2026-10-24）

## 本次交付

两件事：修掉「改档案时辰后旧版完整记录被永久隐藏」的根因，新增档案即时同步到本地文件夹。

### 根因

记录面板取记录时按 `bz_rec_notes_姓名|性别|年|月|日|时|分` 拼键。旧版 `recNoteCandidates()` 在精确键有内容时直接 `return`，不再往历史键看。用户改档案时辰后，新键自动被旧短记录占住，之前那份完整记录仍在库里却再也取不到——面板显示空或残缺，无任何提示。

### 修法

`recNoteCandidates()` 精确键有内容时也继续收集候选，在同生日 / 同姓名历史键里挑出更完整的版本，交给新增的 `recRenderBetter()` 渲染提示条：

> ⚠ 发现更完整的历史版本（53 字，当前 3 字，内容有差异），点此载入：

只给按钮，不自动覆盖 textarea。用户点了才载入，避免另一种无声丢失。

### 本地文件夹同步

档案区新增三个按钮：`📁 本地同步` / `立即同步` / `关闭同步`。

- 基于 File System Access API，用户点一次选目录，句柄存 IndexedDB（`bz_sync_db` / `handles`）
- 之后 `writeArchives()` 与记录输入都触发 `syncTouch()`，1.2 秒防抖后全量落盘
- 落盘四类文件：
  - `archives.json` — 全量档案
  - `records.json` — 全量分析记录
  - `盘面-<姓名>.md` — 四柱（天干·地支·藏干·十神表格）、要位（生肖·命宫·身宫·胎元·胎年·起运）、大运、分析记录
  - `INDEX.md` — 总览表
- 页面加载时 `syncResume()` 查权限，`granted` 静默同步，`prompt` 提示重授权

限制：需 Chrome / Edge + https 或 localhost（`file://` 不支持，按钮会提示）。

## 教训

headless Chrome 在未登录状态下调 `ARCHIVE.loadArchive()` 会走 `APP.doPaipan()`，被登录守卫拦下并弹原生 alert。alert 阻塞渲染线程，`Runtime.evaluate` 永不返回，表现为 WebSocket 超时。CDP 脚本需在 `cmd()` 循环里监听 `Page.javascriptDialogOpening` 并自动 `Page.handleJavaScriptDialog`，或绕开 `doPaipan` 直接调 `RENDER.bindRecPanel()`。
