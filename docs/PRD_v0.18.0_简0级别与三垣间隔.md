# PRD v0.18.0 — 简0级别 + 三垣间隔

> 版本：v0.18.0 | 日期：2026-08-08 | 作者：产品经理 (worker_481a30ed)
> 基于：八字排盘 v0.17.0（`standalone-split.html` + `render.js`）

---

## 一、需求概述

基于 v0.17.0 的四层级简分体系，新增两个改动：
1. **新增「简0」级别**：在 L0 之前插入一级，不显示任何扩展信息，五层级循环。
2. **四柱与三垣间隔**：在四柱表格区和三垣表格区之间增加稳定的视觉分隔。

---

## 三、改动二：四柱与三垣间隔

### 3.1 现状

当前 v0.17.0 中，单人排盘的四柱数据行与三垣数据行紧密相连——最后一个四柱数据行（神煞/空亡等，取决于当前层级）紧接着就是三垣表头 `<tr class="hd">三垣…`。两者之间无任何视觉分隔，用户难以一眼区分「上面是四柱」和「下面是三垣」。

在龙凤胎卡片模式中，三垣区域通过 `.bz-sanyuan-area` 包裹（含独立 `<table>`），与四柱表之间有 `border-top:1px solid var(--bz-card-border)` 和三垣折叠按钮，视觉分隔已存在但不明显。

### 3.2 目标

在四柱表格区与三垣表格区之间，增加**约半行高度（0.75em）的可见间隔**，让用户一眼睛区分上下两个区域。关键约束：

- **稳定**：即使三垣行通过宫位标签添加了内容，间隔空间必须保留，不能被内容撑掉。
- **不随层级变化**：简分级别切换不影响该间隔的显隐。

### 3.3 方案

#### 单人排盘（renderChart）
在四柱数据最后一行与三垣表头之间，插入一个**独立分隔行**：

```html
<tr class="sanyuan-sep"><td colspan="7"></td></tr>
```

- 该行为空行，`colspan="7"` 覆盖年/月/日/时/大运/流年/盘式共 7 列。
- CSS：`height: 0.75em;`，不设 `display:none`，不带 `data-row-type`，不受层级 CSS 规则影响。
- 可选增加顶/底边框或浅色背景增强可见性（如底部 `border-bottom: 2px solid var(--c-line)` 增强分隔感）。

#### 龙凤胎卡片（buildCardHTML）
三垣区域已被 `.bz-sanyuan-area` 包裹（独立 `<table>`），在 `.bz-sanyuan-area` 上增加 `margin-top: 0.75em;` 即可。同时确保 `.chart-wrap` 去除底部多余 margin 避免间距叠加。

### 3.4 为什么不简单地加 CSS margin？

因为在单人模式中，四柱和三垣共用同一个 `<table class="chart">`，margin 无法作用于 table 内部的 tr 之间。最可靠的方式是插入一个实体分隔行，天然不受内容增减影响。

## 四、UI 规格

### 4.1 按钮

- **位置**：排盘界面顶部栏右侧，宫位按钮左侧（同 v0.17.0）。
- **样式**：沿用 `.btn-simple`，始终激活态（`active` class）。
- **文字循环**：「极简」→「简」→「中」→「详」→「全」→「极简」…
- **title 属性**：
  - L0: `简分级别：仅四柱干支骨架（点击展开）`
  - L1: `简分级别：星运自坐（点击展开）`
  - L2: `简分级别：星运自坐纳运纳音（点击展开）`
  - L3: `简分级别：星运自坐纳运纳音空亡（点击展开）`
  - L4: `简分级别：全部信息（点击收起）`

### 4.2 四柱-三垣分隔行

- **高度**：`0.75em`（约半行文字高度）。
- **视觉**：底部带一条分隔线 `border-bottom: 2px solid var(--c-line)`（可选，若觉得纯空白不够明显）。
- **不受层级 CSS 影响**：无 `data-row-type`，不会被任何 `.chart.level-N` 规则隐藏。

## 六、边界条件

| 场景 | 预期行为 |
|------|----------|
| 页面首次加载 | 默认 L0（极简），按钮显示「极简」，所有扩展信息行隐藏，仅见四柱干支骨架 |
| 页面刷新 | 层级重置为 L0（极简） |
| L0 → L1 切换 | 「极简」→「简」，星运 + 自坐出现 |
| L4 → L0 循环 | 「全」→「极简」，回到初始状态 |
| 连续快速点击 | 每次点击正常切换，不丢状态 |
| 龙凤胎双卡模式 | 两张卡片共享同一层级按钮（位于顶部栏），同步切换 |
| 三垣区域折叠/展开 | 与层级切换独立；折叠时三垣整体隐藏，展开时三垣的扩展信息行同样受层级控制 |
| 宫位标签在三垣区添加内容 | 分隔行作为独立 `<tr>` 位于 `.sanyuan-sep`，宫位标签行插入位置在 `updateGongWeiTags()` 中控制，不影响分隔行 |
| 切换大运/流年列 | 不受简0级别影响（`_applyDLUpdates` 使用语义选择器，不受 display:none 干扰） |
| 分隔行在极简模式 | 始终可见（无 data-row-type，不被隐藏），分隔行本身 0.75em 高度保持 |

## 七、验收标准

1. **默认状态**：页面加载后无扩展信息行（星运、自坐、纳运、纳音、空亡、神煞均不可见），按钮显示「极简」。
2. **点击「极简」**→ 显示星运+自坐，按钮变为「简」。
3. **点击「简」**→ 显示纳音+纳运，按钮变为「中」。
4. **点击「中」**→ 显示空亡，按钮变为「详」。
5. **点击「详」**→ 显示神煞，按钮变为「全」。
6. **点击「全」**→ 回到 L0（极简），按钮恢复「极简」。
7. **四柱-三垣分隔**：单人排盘中，四柱最后一行与三垣表头之间有明显 ~0.75em 间隔（带底部分隔线）。
8. **分隔稳定性**：在 L4（全）状态下为三垣区添加宫位标签内容后，四柱-三垣间隔仍保持 0.75em 高度。
9. **龙凤胎卡片**：卡片内四柱表与三垣表之间有 ≥0.75em 间距。
10. **三垣区层级同步**：三垣展开后，其扩展信息行显隐与四柱区同步（同为当前 L 级）。
