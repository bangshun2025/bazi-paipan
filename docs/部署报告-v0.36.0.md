## 2. 新增内容

**① 胎年宫（口径 A：胎元所在年的干支）**

- `algorithm.js`：`taiNianGZ()` —— 胎年干支 = 胎元所在年取年柱干支；跨年界（亥/子/丑月胎元落次年）取生年
- `render.js`：三垣区由四列改五列（**胎年** / 胎元 / 命宫 / 身宫），列宽与年柱列对齐
- `panels/paipan/view.js`：报表三垣表同步加胎年列（表头 + 主星/干/支/藏气四行）
- `api/handler.rb`：`self.tai_nian(eff_year, yue_zhi)`（口径 A，k=(月支序-2)%12 回退 9 个节气月，跨年界次数 (k-9)/12），`/api/paipan` 响应新增 `tai_nian` 字段
- 口径为邦顺裁决：**胎年 = 胎元所在年的干支**（与「受孕之月往前数九个月所在月为胎元、其年为胎年」一致）

**② 宫位面板「胎年宫位」显示开关**

- 宫位 popover 底部新增勾选框「胎年宫位」，默认不显示，旁注「标签可留空 · 默认不显示」
- 勾选后三垣**宫位标签行**新增胎年格，显示各组第 8 槽标签（`GW_INDEX.taiNian = 7`）
- 宫位设置编辑器新增第 8 槽「胎年」输入行（位于胎元之后，可留空）
- 状态存 localStorage `bz_gongwei_show_tainian`，属本地显示偏好，**不入导出/云同步载荷**

**③ 测试**

- `main.js` 新增 TN01–TN09 共 11 条断言（槽位常量、缺省不显示、编辑器第 8 槽、开关关/开渲染、留空无 undefined、真实 DOM 显隐、编辑器保存贯通）
- `scripts/check-release.sh` 门禁追加 `gzEditL7`（静态 id）/ `gzShowTaiNian`（运行时键），兜底链覆盖 `gongwei.js`

**④ 拆笔说明**
