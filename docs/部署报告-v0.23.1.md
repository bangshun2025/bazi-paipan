## 一、变更清单

1. **农历+真太阳时排盘无反应（主 bug）**
   - 根因 1：`APP.calendarType` 是创建时值快照（恒为 'solar'），农历模式下 `doPaipan` 误走公历 DOM 分支 → `inMonth` 为 null → `TypeError` → 排盘静默中断
   - 修复：改为 getter 实时读取（main.js / index.html / standalone.html 三处）
   - 根因 2：`updateSolarPreview` 月份取值只读 `inMonth`，农历模式下同样崩溃（勾选真太阳时时触发）
   - 修复：DOM 自适应 `(inMonthSelect || inMonth)`
2. **真太阳时分钟进位 bug**：小数偏移（59.6 分）取整为 60 分时未进位（显示 04:60），现进位 05:00；`adjH` 改 `let` 以支持进位赋值
3. **ext.yml 版本同步**：v0.23.0 发布时 ext.yml 未升版（滞后），本次对齐至 v0.23.1
