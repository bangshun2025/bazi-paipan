## 2. PM 的定性更正（采纳）

PRD r7 的 **FR3.4.1** 与 **D16** 已**预先登记**「4 列名为通栏图例、不做逐栏像素对齐，**实测困惑则记 R 项**」⇒ 本项性质 = **PRD 预留出口 + R 项留痕 + 可选缓解措施**，**不是 PRD 漏项、不是需求变更**。

## 3. 最终 recipe（以本节为准；ADR §15.3 的 C3 片段为契约依据）

```css
/* 仅在 ≥1280px 生效；<1280px 保持浏览器默认 table/thead 呈现，不加任何覆盖 */
@media (min-width:1280px) {
  .xy-table { display:block; }                                      /* 显式化宽度基准：100% = 表区宽 */
  .xy-table thead { display:block; width:calc((100% - 32px)/3); }   /* = 一栏宽；三栏 column-gap:16px ×2 */
  .xy-table thead tr { display:grid; grid-template-columns:56px 76px minmax(0,1fr) minmax(0,1fr); gap:4px; }
}
```

**与 ADR §15.3 的唯一差异**：`gap:0` → **`gap:4px`**（与数据行 `.xy-table tbody > tr` 同构），属实现细节精化，不改变契约语义（仍为「对齐第 1 栏列模板」），也仍在 ±12px 断言内（更优）。

## 4. 实测对照（真实 `index.html`，Chrome 1512×827，`.xy-table` 宽 1162px，一栏宽 376.7px）

| **A** `thead{width:calc((100% - 32px)/3)}` + `gap:0` | 56 / 76 / 122.3 / 122.3 | **[0, −4, −8, −6]** | 可用（±12px 内） |
| **B（最终）** 同 A 但 **`gap:4px`** | 56 / 76 / 116.3 / 116.3 | **[0, 0, 0, 0]** ✅ | 与数据行**逐像素同构** |

**对 PM「塌缩陷阱」的回应**：PM 在隔离模型里观察到的「两个 `1fr` 轨道塌成 2px」在**真实页面未复现**（A/B 的 `1fr` 轨道分别正常解析为 122.3 / 116.3px ⇒ 隔离模型中 `thead` 宽度被解析为内容宽度所致）。但 PM 的担忧本质正确，**已被 C 变体以另一种形式证实**：若忘记把 `thead` 宽度收窄到一栏宽，错位可达 **392.7px** ⇒ **宽度基准必须显式**（`.xy-table{display:block}` + `thead{width:calc((100% - 32px)/3)}`，不依赖继承）。
⇒ 断言判据因此定为：`th`=4 **且** `th[i].left` 与第 1 栏数据行第 i 字段偏差 **≤12px** **且** `th[i].width ≥ 40px`（防塌缩式假绿；实测最小 `th` 宽 = 56px）。

## §8.8 引用纪律（Leader 授权新增，2026-09-11）

**触发**：v0.30.0 收口期连续出现三类「引用 / 取证」事故——① 实施记录 L5 **悬空引用**（引了任何目录都不存在的 `ADR-v0.30.0-冻结期纪事.md`）；② 发布师《发布准备》把内测容器 `.bak_v0.30.pre/` 误记为「**无**」（实测**有**）；③ 以「`find "*纪事*"` 搜不到」推论「文件不存在」。

**纪律（三条，机械可执行）**：

1. **落笔前必须现场核到实物**：凡在本文件或任何文档中写入另一个文件的**文件名 / md5 / 行数**，落笔前当场 `ls`（全名逐字符）+ `md5 -q` + `wc -l`，**不得凭记忆、不得沿用上一次的值**。
2. **搜索式取证无效**：「关键词搜不到」**≠**「文件不存在」——真名可能不含该关键词（例：本纪事真名含 `_RECORD_ADRv1.4冻结期_C3最终recipe与留痕_`，**字面不含「纪事」二字**）。⇒ **引用核准的唯一可靠判据 = 全名逐字符比对 + 引用点交叉**（如 ADR §13 的引名 ↔ 磁盘实体名）。
3. **引用要带出处**：写「**文件名 + 所引 §**」；引用**活文档**时另记 **md5 + 行数 + 取值日期**。**自指除外**：本文件自身的 md5 不入正文（写入即改变自身哈希）——沿用 §8.6 纪律。
4. **引用点冻结（Leader 第 47 轮）**：**任何 md5 一经写入他人文档即成为引用点，引用点只接受 Leader 分发的冻结值**。⇒ 一切**活文档**的 md5 落笔时一律标注为「**取值日期快照**」，正式引用以**现场 `md5 -q` 现测**为准；本编排已**四次**踩中「引用点与真相源有时点差」（`ADR-v0.30.0-冻结期纪事` 悬空引用 → `.bak_v0.30.pre` 误记 → 纪事 md5 沿革 → PM 备案 md5 沿革），根因同一：**引用点写死、真相源继续动**。

**中文路径附加纪律**：`git ls-files` 一律加 `-c core.quotepath=false`（否则中文名被转义成八进制 `\347\272\263…`，统计必然漏计）；路径比对前做 `unicodedata.normalize('NFC', …)`（本机实测：167 个跟踪文件中 `NFC≠自身` = **0**、`docs/` 112 个中文名 = **0**，属**零成本防御**而非活跃坑）。
