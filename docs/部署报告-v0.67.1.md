## 本次改了什么

v0.67.0 的「勾选十神则左对齐」规则只覆盖四柱，三垣（胎元/命宫/身宫）仍居中，与上方四柱明显错位。

本次把同一条规则扩到三垣四行：主星、天干、地支、藏气。

### 代码改动

1. `render.js` `renderChart`：三垣天干行 `<tr class="rg" data-sec="sanyuan">` 补 `data-row-type="sy-gan"`，地支行补 `data-row-type="sy-zhi"`（此前这两行没有行类型标记，门控规则碰不到）。
2. CSS（三产物同改）：`.chart.ssh-on` 选择器名单追加 `sy-rs`、`sy-gan`、`sy-zhi`、`sy-cg`。纳音/纳运/主坐/自坐/空亡/神煞保持居中，与四柱口径一致。
3. `render.js` `_mdlFillCell`：补 `sy-gan → ln1`、`sy-zhi → dy2` 映射。**这是隐患修复**——原函数靠「无 data-row-type 且 sec 含 sanyuan」识别三垣干支行，新增行类型后该条件失效，多运流注入会把三垣单元格写空。
4. `main.js` 断言：新增 X14（勾选时三垣四行均 `left`）、X15（三垣与四柱左缘内距同为 8px）、X16（未勾选时四行均 `center`），另加 2 条 MLT 回归锁（三垣干行/支行者大运二列内容非空且正确）；同步 `v0.29 T02` 三垣行序期望为 `['sy-rs','sy-gan','sy-zhi','sy-cg','xingyao',…]`。
