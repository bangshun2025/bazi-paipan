## 一、变更清单

### 修复 1：AI 录入识别农历与县份
- **日期识别**：`年/月/日` 正则「日/号」后缀改为可选——「1986年7月26（农历）」此前报「未能识别完整日期」（26 后是括号不是日/号）
- **农历标志**：文本含「农历/阴历/旧历/老历」（含括号写法）→ 自动切农历模式排盘，预览标注「（农历）」
- **出生地增强**：
  - 省名支持无后缀写法（「广东」→广东省、「北京」→北京市）
  - 区县支持省县写法（「南丹」→南丹县、「海淀」→海淀区）
  - 直辖市省=市（北京市）不再因省名替换导致城市/区县失配——地址匹配改用原始文本 t0 基准，替换清理仍用 t（防污染姓名提取）

### 修复 2：农历模式排盘失效（AI 录入填表崩溃）
- 根因：`doAiParse` 固定写 `inMonth.value`，农历模式下该控件已被 `toggleCalendar` 替换为 `inMonthSelect` → `Cannot set properties of null` → 填表中断、排盘不执行
- 修复：先按识别结果切日历（toggleCalendar 重建月控件），再按模式分派填 `inMonthSelect` 或 `inMonth`
