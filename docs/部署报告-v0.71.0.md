## 一、本版内容：运流区移到下方

**需求**：点十神或十干按钮后，运流整区从右方调整到下方。

**触发条件**：勾选十神或十干任一组（`sshSel.length || ganSel.length`）就下移，全部取消即回右栏。

**为什么不再在右栏里修**：v0.67.0 为了让左盘左对齐后右盘不显得突兀，给 `.luck-col` 加了 `ssh-on` 左对齐。副作用有两个——格子从居中变贴左；`text-align` 变化影响 auto 表格的列宽算法，整块往左缩。与其在右栏里继续调和，不如把运流区放到主表下方，空间全宽，816px 的表格不再横向溢出 212px。

**实现**：新增 `luck-moved` 布局，不动双胞胎卡在用的 `luck-below`。

```css
.body-cols.luck-moved { display:flex; flex-direction:column; align-items:flex-start;
                        width:fit-content; max-width:100%; margin-left:auto; margin-right:auto; }
.body-cols.luck-moved .main-col { width:auto; max-width:100%; }
.body-cols.luck-moved .luck-col { min-width:0; position:static; margin-top:12px; width:auto; max-width:100%; flex:0 0 auto; }
```

三个关键决策：

1. **为什么不复用 `luck-below`**：它是 `display:block`，`.chart { width:100% }` 会让主表撑到 1302px 全宽，四柱被拉得很开。第一版实测就是这个效果，截图里天干地支间距巨大。改成 flex column + `fit-content` 后主表维持 680px。
2. **`width:fit-content` + `margin:auto`**：下移后整块居中，主表与运流区左缘都落在 347px，左边缘对齐。若只用 `align-items:flex-start`，整块会贴左，右侧空 484px。
3. **分析记录模式优先**：`recOn` 为真时不下移。第一版把 `!sshOn` 写进了 `recOn` 的条件里，回归直接报出 2 条失败（`REC T04: 重渲染后记录面板仍开`、`REC T04: 运流区仍在左下`）——记录模式本来就要把运流区移进 `main-col` 左下，两个下移机制不能同时生效。
