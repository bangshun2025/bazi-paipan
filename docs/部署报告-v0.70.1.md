## 一、本版修的两个问题

### 问题一：十干面板不是点击才弹出，而是一进页面就摊开

**原因**：CSS 里只有 `.gz-popover / .ssh-popover` 带 `display: none` 与 `.open → display: block` 规则。v0.70.0 新增的 `.gan-popover` 没有并进这两条规则，浏览器按默认 `display: block` 渲染，面板就一直可见。

**修法**：三产物 CSS 把 `.gan-popover` 并入 popover 规则组，共四处：

| 位置 | 规则 |
|---|---|
| 基础 | `.gz-popover, .ssh-popover, .gan-popover { display:none; position:absolute; … }` |
| 展开 | `.gz-popover.open, .ssh-popover.open, .gan-popover.open { display:block; }` |
| 移动端 | `@media (max-width:480px)` 里的 fixed 居中弹层 |
| 对比页 | `.cmp-gz-host` 的 z-index |

### 问题二：十神名会顶进十干区

**现象**：勾选十干组后，某个天干在「德性」组里没有配词（如 壬、庚、丁），该天干的十神名就左移，占到了十干区的位置，视觉上十神跑进了十干区。

**原因**：渲染函数按「有值才输出」判断——无十干词 → 不输出十干块 → 十神块自然左移顶位。

**修法**：`sshGanVert / sshCgVert` 改为按「十干组是否勾选」决定结构：

| 状态 | 渲染 |
|---|---|
| 十干组已勾选 | 固定两区 `天干 → [十干区] ｜ [十神区]`；该干无词则十干区输出 `.gy-ns.gy-empty` 占位（1.1em），十神块始终带 `gy-sep` 竖线 |
| 十干组未勾选 | 维持 v0.69.0 旧布局（十神名紧跟天干，无竖线），不多占宽度 |

天干单元、藏气层、大运/流年、多运多流年格、三垣区共用这两个函数，一处改动全局生效。
