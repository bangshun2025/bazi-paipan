# PRD：v0.20.0 常用宫位分级

## 一、版本信息

- **版本号**：v0.20.0
- **依赖版本**：v0.19.0（standalone-split.html）
- **改动范围**：gongwei.js（数据层 + 渲染层），constants.js（如有新 key），main.js（入口如有新增调用）
- **改动类型**：功能增强——宫位体系从「平铺 14 种」升级为「常用 / 全部」两级管理

---

## 二、功能概述

当前宫位体系只有一个层级：14 种宫位组平铺在设置页和下拉面板中。用户实际高频使用的只有其中几种，但下拉面板和标签行始终遍历全部组，信息密度低。

**v0.20.0 引入「常用宫位」分级**：

```
全部宫位（14 种，可增删改）
    └── 常用宫位（子集，可增减、独立排序）
            └── 选中显示（子集，决定排盘上是否出现）
```

三层关系一句话：**全部是仓库，常用是货架，选中是摆上桌的。**

核心变化：

| 维度 | 现状（v0.19.0） | 目标（v0.20.0） |
|------|-----------------|-----------------|
| 下拉面板（排盘页「宫位 ▾」） | 显示全部宫位组 | **只显示常用宫位** |
| 设置页结构 | 单一列表 + 回收站 | **两个 tab：「全部宫位」「常用宫位」** |
| 「打勾」语义（全部宫位 tab） | 选中 = 排盘显示 | **改为：打勾 = 加入常用宫位** |
| 「打勾」语义（常用宫位 tab） | 无此 tab | **打勾 = 排盘显示（承接旧"选中"语义）** |
| 排序影响 | 排序 → 下拉面板 + 标签行顺序 | 全部排序 → 不影响常用；**常用排序 → 同步标签行顺序** |
| 默认按钮 | 无 | 「默认」按钮：**常用宫位顺序同步全部宫位顺序** |

## 三、需求详述

### 3.1 两种宫位的定义

#### 3.1.1 全部宫位

- **定义**：系统中存在的所有宫位组，含 14 种预置 + 用户自定义组。
- **数据源**：`gongWeiGroups[]`（即现在的 `bz_gongwei_groups`），不做任何变更。
- **操作**：新增、编辑、删除、回收站、拖拽排序——与 v0.19.0 设置页**完全一致**。
- **新增语义**：每个宫位组旁边多一个 **「常用」勾选框**。打勾 → 该组出现在「常用宫位」tab 中；取消 → 从常用中移除。

#### 3.1.2 常用宫位

- **定义**：全部宫位的**子集**，用户标记为"常用"的宫位组。
- **数据源**：新 localStorage key `bz_gongwei_fav`，存储宫位组名称数组，**顺序 = 常用宫位的显示顺序**。
- **操作**：勾选（决定排盘显示）、排序（拖拽/上下箭头）、移除（从常用中拿掉，但不删除宫位组本身）。
- **初始值**：首次使用时，默认 14 种预置宫位**全部为常用**，顺序与全部宫位一致。

#### 3.1.3 选中显示

- **定义**：常用宫位中，用户勾选"在排盘上显示"的组。
- **数据源**：沿用 `bz_gongwei_selected`（即现在的 `selectedGongWei[]`），语义不变。

### 3.2 设置页两个 Tab

设置页（`openGzSettings()` 打开的浮层）结构从「单一列表 + 回收站」变更为：

```
┌─────────────────────────────────────────┐
│  宫位设置                          [✕]  │
├─────────────────────────────────────────┤
│  [ 全部宫位 ]  [ 常用宫位 ]              │  ← 两个 tab
├─────────────────────────────────────────┤
│                                         │
│  （当前激活 tab 的内容区域）              │
│                                         │
└─────────────────────────────────────────┘
```

#### 3.2.1 「全部宫位」tab

布局：与当前设置页列表一致（宫位组名称 + 预览标签 + 编辑/删除/排序按钮），在**每个宫位组左侧**新增一个 ☆（或 checkbox）用于「加入常用」。

- ☆ 实心/打勾 = 在常用宫位中
- ☆ 空心/未勾 = 不在常用宫位中
- 点击 ☆ 即时切换，无需确认
- 排序（拖拽/上下箭头）：调整全部宫位的排列顺序，**不影响常用宫位顺序**。
- 删除宫位组：若该组在常用中，**自动从常用中移除**。
- 回收站入口：保持现有「回收站(N)」按钮。

#### 3.2.2 「常用宫位」tab

布局：仅显示已标记为常用的宫位组列表，每行含：

- **checkbox**（打勾 = 排盘显示，即 `selectedGongWei`）
- **宫位名称 + 预览标签**
- **拖拽手柄** + 上移/下移按钮（排序）
- **移除按钮**（从常用中拿掉，不删除宫位组）

排序规则（关键）：
- 拖拽/上下箭头调整常用宫位顺序 → **同步影响排盘上宫位标签行的显示顺序**。
- 全部宫位的排序变化**不会自动同步**到常用宫位（手动调整过的顺序优先）。
- 「默认」按钮：将常用宫位顺序**重置**为与全部宫位中这些组的相对顺序一致。

> **「默认」按钮行为**：重新排列 `bz_gongwei_fav`，使其中各组按它们在 `gongWeiGroups` 中的出现顺序排列。**不改变哪些组在常用中**（不打勾的不变、打勾的不变），只改变顺序。

### 3.3 下拉面板（排盘页「宫位 ▾」）

**改变**：下拉面板 `renderGongWeiPanel()` 中的 checkbox 列表**只显示常用宫位**（即 `bz_gongwei_fav` 中的组），按常用宫位顺序排列。

- 若常用宫位为空：下拉面板显示「暂无常用宫位，点击 ⚙ 宫位设置添加」提示文字。
- 全选/清空按钮：只作用于常用宫位（不是全部宫位）。
- ⚙ 宫位设置按钮：保持现有行为，打开设置页。

### 3.4 标签行显示顺序

当前 `buildGongWeiTagRows()` 遍历 `gongWeiGroups`（全部宫位顺序），过滤 `selectedGongWei` 来决定显示哪些行。

**改为**：遍历 `bz_gongwei_fav`（常用宫位顺序），过滤 `selectedGongWei`。这样常用宫位排序变化后，标签行的上下排列顺序即时联动。

## 四、数据模型

### 4.1 localStorage 键位

| Key | 类型 | 说明 | 变更 |
|-----|------|------|------|
| `bz_gongwei_groups` | `Array<Group>` | 全部宫位组（含顺序），结构不变 | 无 |
| `bz_gongwei_fav` | `Array<string>` | **新增**：常用宫位组名称列表，顺序 = 常用宫位显示顺序 | 新增 |
| `bz_gongwei_selected` | `Array<string>` | 排盘显示的宫位组名称，语义不变 | 无 |
| `bz_gongwei_trash` | `Array<{id, group, deletedAt}>` | 回收站，结构不变 | 无 |

### 4.2 `bz_gongwei_fav` 数据结构

```js
// 示例
["信息", "做功", "亲缘", "生理", "记忆"]
//   ↑ 顺序即常用宫位 tab 和下拉面板的显示顺序
```

- 数组元素为宫位组 `name`（与 `gongWeiGroups[].name` 对应）。
- 顺序即常用宫位的排列顺序，直接影响标签行上下顺序。
- 只包含"已标记为常用"的组，不包含不在常用中的组。

### 4.3 旧用户数据迁移（关键）

**场景**：老用户已有 `bz_gongwei_groups` 和 `bz_gongwei_selected`，但没有 `bz_gongwei_fav`。

**迁移策略**（首次加载时自动执行）：

```
if (localStorage 中没有 bz_gongwei_fav) {
    bz_gongwei_fav = gongWeiGroups.map(g => g.name);
    // 即：所有现有宫位组默认加入常用，顺序与全部宫位一致
}
```

**迁移结果**：
- 老用户升级后，所有 14 种（含自定义）自动成为常用宫位。
- 下拉面板和之前一样显示全部组（因为全部都是常用）。
- 老用户体验零变化——他们可以后续手动调整常用范围。
- `bz_gongwei_selected` 保持不变——原来打勾的继续打勾。

### 4.4 数据一致性约束

| 操作 | 对 `bz_gongwei_fav` 的影响 | 对 `bz_gongwei_selected` 的影响 |
|------|---------------------------|-------------------------------|
| 全部宫位 tab：勾选"加入常用" | 将该组名追加到 `fav` 末尾 | 无 |
| 全部宫位 tab：取消"加入常用" | 从 `fav` 中移除该组名 | **同时从 `selected` 中移除**（不在常用中的组不能在排盘显示） |
| 全部宫位 tab：删除宫位组 | 若在 `fav` 中则移除 | 若在 `selected` 中则移除 |
| 全部宫位 tab：排序 | **不影响** `fav` | 无 |
| 常用宫位 tab：勾选"排盘显示" | 无 | 添加/移除 |
| 常用宫位 tab：排序 | **重排** `fav` 顺序 | 无（selected 是集合，无序） |
| 常用宫位 tab：移除 | 从 `fav` 中移除 | **同时从 `selected` 中移除** |
| 常用宫位 tab：点击「默认」 | 按 `gongWeiGroups` 顺序重排 `fav` | 无 |

## 五、交互流程

### 5.1 下拉面板交互

```
用户在排盘页点击「宫位 ▾」
    → 弹出 Popover，列出常用宫位（checkbox 列表，按常用顺序排列）
    → 勾选/取消 → 即时更新排盘标签行
    → 点击「⚙ 宫位设置」→ 关闭 Popover，打开设置页
```

### 5.2 设置页 - 全部宫位 tab

```
用户打开设置页 → 默认显示「全部宫位」tab
    → 每个宫位组左侧有 ☆ 图标（实心=在常用，空心=不在常用）
    → 点击 ☆ → 切换常用状态，即时生效
    → 编辑/删除/排序/回收站 — 与 v0.19.0 行为一致
    → 排序全部宫位 → 不影响常用宫位 tab 的顺序
```

### 5.3 设置页 - 常用宫位 tab

```
用户切换到「常用宫位」tab
    → 显示常用宫位列表（按常用顺序排列）
    → 每行：checkbox（排盘显示）+ 名称 + 标签预览 + 排序按钮 + 移除按钮
    → 勾选/取消 checkbox → 即时更新排盘标签行
    → 拖拽/上下箭头排序 → 即时更新排盘标签行顺序
    → 点击「移除」→ 宫位组从常用中移除（不删除），列表刷新
    → 点击「默认」→ 顺序重置为与全部宫位一致
```

### 5.4 关闭设置页

```
用户关闭设置页
    → 若常用宫位选中状态有变化 → 刷新下拉面板（rebuildGzCbGrid）+ 刷新标签行（updateGongWeiTags）
    → 与 v0.19.0 closeGzSettings() 行为一致
```

## 七、边界情况

### 7.1 删除宫位组对常用与选中的影响

- 全部宫位 tab 删除某组 → 若该组在 `bz_gongwei_fav` 中，**自动移除**；若在 `bz_gongwei_selected` 中，**自动移除**。
- 常用宫位 tab 点击「移除」→ **仅从 `bz_gongwei_fav` 中移除**，宫位组本身不删除（仍在全部宫位中）。同时从 `bz_gongwei_selected` 中移除（安全清理）。

### 7.2 新增宫位组

- 在全部宫位 tab 新增自定义宫位组 → **默认不加入常用**（☆ 空心）。用户需手动勾 ☆。
- 这与旧用户迁移策略（全部默认常用）不同，原因是：新增是用户的主动行为，默认不常用更合理——预置 14 种是"出厂设置"全部常用，自定义是"按需添加"。

### 7.3 常用宫位为空

- 下拉面板：显示「暂无常用宫位，点击 ⚙ 宫位设置添加」。
- 常用宫位 tab：显示空状态提示（如「暂无常用宫位，请在全部宫位中标记 ☆」）。
- 排盘标签行：无标签行（因为 `selectedGongWei` 必然为空）。

### 7.4 手动排序优先语义

- 用户在常用宫位 tab 中手动调整顺序后，**全部宫位 tab 的排序变化不再影响常用宫位顺序**。
- 用户点击「默认」按钮后，重新同步顺序，**之后手动调整又可再次脱离**。
- 实现上不需要额外的"是否手动调整过"标记——常用宫位顺序始终以 `bz_gongwei_fav` 为准。全部宫位排序变化不写入 `fav`，「默认」按钮显式同步。

### 7.5 旧用户数据迁移（重复强调）

- 迁移在 gongwei.js 初始化时执行（`initGongWeiData()` 中检测 `bz_gongwei_fav` 是否存在）。
- 迁移只需执行一次——写入 `bz_gongwei_fav` 后，下次加载不再触发。
- 迁移不修改 `bz_gongwei_selected`，已选中的继续选中。
- 迁移后 `bz_gongwei_fav` 的顺序 = `gongWeiGroups` 的顺序。

### 7.6 回收站恢复

- 从回收站恢复宫位组 → 该组回到 `gongWeiGroups` 末尾。
- **不会**自动重新加入 `bz_gongwei_fav`（即使用户删除前它在常用中）。这是有意设计：删除 = 用户明确不要了，恢复后默认不在常用，需要手动加回。
- **不会**自动重新加入 `bz_gongwei_selected`。

### 7.7 编辑宫位组名称

- 在全部宫位 tab 编辑某组名称 → 需同步更新 `bz_gongwei_fav` 和 `bz_gongwei_selected` 中对应的旧名称。与当前 `updateGroup()` 中对 `selectedGongWei` 的处理一致，新增对 `bz_gongwei_fav` 的同步。
