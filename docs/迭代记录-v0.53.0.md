## 关键修复

1. **em 基准错位**：.ssh-cg-i 自带 font-size:11px 使 min-width:3.2em 与藏气干行（12px 基）不等宽，逐位 left 累积偏移 29px。改为外层 span 12px 基准 + 内层 .ssh-cg-i-t 11px，maxDiff≤2px。
2. **面板注入漏做**：check-release 只比对内外一致，四处 topbar 模板漏注 SSH.renderPanel() 门禁不报；CDP 实测 hasPanel:false 兜住。
3. **断言自身 bug**：T13/T14 mkPill 少传支参导致 shiShen 为空；v0.29 typeSeq 行序被组行插入破坏 → 跳过 data-ssh-group。
4. **script 切段规则**：SSH 内联段必须独立 `<script>` 块（`src.rfind('<script>', 0, idx)`），否则 check-release 切段错乱。

## 实测坑留档

- 主页 `.page` 容器默认 display:none、`#authOverlay` 登录遮罩默认显示——JS 直调排盘（绕过登录守卫）后必须展开 .page、隐藏遮罩，否则截图空白且 rect 全 0（querySelector 照常命中，断言会假过）
- `.gz-settings-btn` 类被宫位面板复用，SSH 弹窗入口选择器必须加 `#ssh-popover` 前缀
- 大运切换真实用户路径是 `[data-dy]` 导航条点击 → hiDy + updateCardDyLnColumns；表格 col-dy 单元格不是点击入口
- localStorage 持久化跨会话残留会污染 ?test=1 断言（探针跑完必须还原映射或清 key）
