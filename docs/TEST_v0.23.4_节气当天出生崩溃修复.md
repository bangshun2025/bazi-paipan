## 二、缺陷复现（修复前基线）

### 2.1 复现步骤

1. 打开排盘页面（standalone.html 或 index.html）。
2. 录入：奕澄老公，男，1987年5月6日 6:30，北京时间。
3. 点击排盘。

### 2.2 修复前现象（已由诊断确认）

- 页面报错：`排盘出错：Cannot read properties of null (reading 'getUTCFullYear')`
- 根因链：
  1. 1987-05-06 恰逢立夏当天（立夏时刻 17:05），出生 6:30 在立夏前 → 正确月柱应为辰月；
  2. `monthPillar()` 用节气**日期零点**而非完整时刻判断 → 6:30 >= 立夏日零点 → 月柱错判为巳月（乙巳）；
  3. 月柱错为巳月后逆排起运，找巳月节气立夏发现在未来 → 回退到 1986 年立夏 → 间隔 365.12 天 → 起运 121 年 8 月；
  4. 起运日期 2109 年 1 月超出节气表（1000-2100）→ 交运渲染 `getSolarTerm(2109,...)` 返回 null → standalone.html ~7210/7216 行无判空直接 `.getUTCFullYear()` → 崩溃。

### 2.3 关键事实（已实测确认）

| 项 | 值 |
|----|-----|
| 1987 立夏时刻（BJT） | 1987-05-06 17:05:35 |
| 1987-05-06 06:30 | 立夏前 → 应属辰月 |
| 1987-05-06 18:00 | 立夏后 → 应属巳月 |
| 1987 年柱 | 丁卯（丁年五虎遁：寅壬寅 → 辰月 = 甲辰） |
| 丁年巳月 | 乙巳 |
