## 2. 新增内容

**① 入口迁移 + 档案勾选选盘**

- 主操作行「▦ 排盘对比」按钮移除，入口移入档案面板头部（「▦ 盘面对比」）；每条档案行首新增勾选框，按档案 id 写入 `bz_cmp_state`（对象格式 `{type:'arch', id}`），与列表排序无关——搜索、标签筛选自然可用于挑盘
- 未打开对比页时勾选只存状态，打开时全量渲染

**② 名字条（拖序 + 定位）**

- 工具栏下方横排名字 chip（序号 + 显示名），拖动名字即调整排盘顺序（HTML5 DnD，dragend 按 DOM 顺序回写并同步重渲）；点击名字平滑滚动定位卡片；卡片 ⠿ 手柄拖序保留，两路径共用状态
- 拖动镜像同步（`_cmpPairMove`）：拖名字条与拖卡片手柄互为镜像

**③ 简分级別**

- 首页与对比页各有「简分」按钮（宫位式下拉面板），五档预设（少/简/中/详/全）+ 七项自由勾选（星曜/纳音/纳运/星运/自坐/空亡/神煞），按钮文本实时显示当前档位

**④ 五区显隐勾选栏**

- 对比页常驻五区勾选（运流项/藏气区/三垣区/运流区/节气区，`_cmpSecs`），卡片加 `sec-*-off` 类与行级勾选分层互不影响
- **默认勾 00100**（只勾三垣区）——打开对比页即窄卡三盘布局；藏气行高统一 calc 公式；起运行并入运流区

**⑤ 对比页布局功能（本轮收口）**

- 布局按钮组一行 1–6 盘可选（`COMPARE.setCols` + `bz_cmp_layout`），CSS `--cmp-cols` 变量控制 N 列换行
- **缩放与布局解耦**：缩放落在 `track.style.zoom`（父容器），不影响卡内部布局计算——放大后行盘数恒定不挤换行
- 勾运流项后表格撑不破卡：`.cmp-card` `min-width:0; overflow-x:auto`，卡仍贴公式宽
- **名字条可折叠**：工具栏「名字」按钮开合（`bz_cmp_bar` 持久化），收起省一行高度
- 三项均持久化（`bz_cmp_layout` / `bz_cmp_zoom` / `bz_cmp_bar`）

**⑥ 测试**

- `main.js` 断言扩至 **876 条**（含布局持久化 5 条新增：zoom 落 track / 行盘数不变 / 名字条收起 / 展开恢复 / 持久化）
