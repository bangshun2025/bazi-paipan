## 一、本版内容

**需求**：流月、流日的干支要换行。格式如下——

```
一月      10/9
甲寅      甲辰
```

流月：新历显示「1月」，农历显示「一月」。

**旧格式的问题**：每个格子是「日期 干支」挤一行，列宽 70px 装不下，浏览器自动折行把干支拆开，实际渲染成「10/8 乙」/「卯」——天干地支被劈成两行，看着别扭。

**新格式**：日期独占一行，干支作为一个整块独占一行。

## 二、实现

**render.js**（`flowTable` 内）：

```js
var label = kind === 'month'
  ? (flowNewCal && item.start ? (item.start.getUTCMonth() + 1) + '月' : cnMonthLabel(index))
  : (item.date.getUTCMonth() + 1) + '/' + item.date.getUTCDate();
return '<button …><span class="flow-date">' + label + '</span>'
  + '<span class="flow-gz"><span class="' + wxClass(item.gan) + '">' + item.gan + '</span>'
  + '<span class="' + wxClass(item.zhi) + '">' + item.zhi + '</span></span></button>';
```

新增汉字月份表：

```js
var CN_MONTHS = ['一', '二', '三', '四', '五', '六', '七', '八', '九', '十', '十一', '十二'];
function cnMonthLabel(index) { return CN_MONTHS[index] + '月'; }
```

**CSS**（三产物同步，加在 `.flow-date` 之后）：

```css
/* v0.73.0: 流月/流日改两行式 —— 日期在上、干支整块在下，农历月用汉字 */
.flow-table .li { display:flex; flex-direction:column; align-items:center; justify-content:center; }
.flow-table .flow-date { min-width:0; margin-right:0; }
.flow-gz { display:inline-flex; white-space:nowrap; }
```

两条必要覆盖：

1. `.flow-date` 原本 `min-width:32px; margin-right:4px`（为横排设计），纵排后要去掉，否则日期不居中。
2. `.flow-gz` 用 `inline-flex`，天干地支作为 flex 子项不会被折断——这是「干支不拆开」的关键，`white-space:nowrap` 只是兜底。

`.flow-table .li` 特异性 (0,2,0) 与 `.liu-row .li { display:block }` 相同，靠位置在后生效。

## 六、遗留观察

1. **流月的列内顺序是竖排递增**：第 1 列是一月/二月，第 2 列是三月/四月……横着读第一行是奇数月、第二行是偶数月。这是 `perColumn = Math.ceil(items.length / 6)` 的既有行为，本版未改。若希望横读为 1-6 / 7-12，需改分配逻辑。
2. **右列比左列短**：面板 525px vs 运流表 818×479 + 节气表 210，右列底部仍有留白。
3. **未勾选十神时右栏运流表仍溢出 212px**，v0.71.0 遗留。
4. 十干「德性」组建议词未落地。
