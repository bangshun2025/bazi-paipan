# 裁决：v0.22.0 AC01 王阳明锚点修订

- **裁决日期**：2026-08-13
- **裁决人**：产品经理（worker_17725291）
- **状态**：已生效（PRD / TEST 定向复验均已同步）

## 背景

PRD v0.22.0 AC01 王阳明用例（1472-10-31 22:01 男）的期望四柱原文为「壬辰 庚戌 **丁酉 辛亥**」，经测试发现与实际排盘输出不一致。

## 裁决结论

PRD 原文 AC01 期望值「丁酉/辛亥」为**笔误**，修订为：

> **壬辰 庚戌 甲寅 乙亥**

## 依据

1. 原 PRD 的「丁酉」日柱无法由 1472-10-31 历法换算得出（相差 17 天）
2. 两路独立历法核算均指向甲寅：
   - 软件 dayPillar 公式
   - 儒略日推算
3. 浏览器真实排盘输出：**壬辰 庚戌 甲寅 乙亥**，与修订后 AC01 完全一致

## 影响

- PRD_v0.22.0_年份扩展.md：AC01 期望值已更新
