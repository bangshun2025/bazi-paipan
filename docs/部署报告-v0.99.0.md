# 部署报告 · v0.99.0（听懂通根 + AI 理解）

- 日期：2026-11-07
- 需求（邦顺）：「七柱天干全盘无根，这个都听不懂？我需要 AI 能听懂的，我用的是自然语言」
- 结论：**已上线，线上五产物逐字节对账一致，线上 2041 条断言全绿**

## 一、为什么之前听不懂

两处真实缺口，不是措辞问题：

1. 判据里没有「根」。整套 DSL 只有透干、十神、合冲刑害，没有「天干在地支藏干里找同五行」这一条。
2. 「七柱」不是四柱。旧引擎只认 年/月/日/时；胎元、命宫、身宫（三垣）算得出来，却没进判据的视野。

所以哪怕把话说得再标准，引擎也无处安放。这一版把两处都补齐了。

## 二、这版能听懂什么

| 说法 | 理解成 |
| --- | --- |
| 七柱天干全盘无根 | 七柱天干全部无根（通根口径） |
| 天干无根 | 四柱天干全无根 |
| 日主无根 / 日干无根 | 只查日干 |
| 天干全部有根 / 天干有根 / 天干有根 3 个 | all / any / count=3 |
| 一个木都没有 / 缺木 / 七柱缺金 / 天干缺水 | 五行分布：指定范围内该五行 ×0 |

证据是可见的，不是黑箱：生成横幅会写清「七柱天干辛庚辛庚辛辛辛 全无根（七柱地支藏干里没有同五行）」或「四柱天干地支里没有木（木×0）」。

## 三、认不出的怎么办

规则认不出的说法，候选条末尾多一个「🤖 让 AI 理解」：

- 有 API Key：自由中文 → 同一套可执行条件 → 本地编译校验 → 通过才用，并标注「🤖 AI 理解：」
- 模型说这套条件表达不了：直说「AI 说这句算不了」，并给替代说法，不硬猜
- 没配 Key：提示「填一次 API Key（只存本机）」并直接打开设置

**边界**：AI 只做翻译。判定、扫描、排盘全部在本地，模型不参与算命。

## 四、口径与证据

- 七柱 = 四柱 + 胎元 + 命宫 + 身宫；三垣缺失时按 `taiYuan()/mingGong()/shenGong()` 现算
- 2000-01-01 寅时：七柱地支 = 卯子午寅卯卯卯（断言 10 固定）
- 扫描成本：392 万候选的快速扫描路径同步换七柱，单盘多三次纯计算，实测 39387 个出生时刻 / 114ms
