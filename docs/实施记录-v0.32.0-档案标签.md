## 需求（原话）

1. 档案里加标签设置：设在每个名字的「✏️ 修改」**之前**，留空、直接填即可；页面可加宽；标签可多加（一条档案多个标签）。
2. 默认标签：可指定打开档案时默认显示哪一个标签；点「默认标签」按钮弹出全部标签，勾选其一即为默认。

## 实现

### 数据
- 档案条目新增可选字段 `tags: string[]`（写回 `bz_archives_v2`，保留 `id/updatedAt` 等既有字段不改）
- 默认标签：`localStorage['bz_archive_default_tag']`（空则删键）

### 交互
- 行内标签框 `<input class="archive-row-tags">` 位于 `✏️ 修改` 之前；分隔符 `空格 , ， 、 ; ； |`，单条上限 12 个；回车落库
- 落库只重绘标签栏、不重绘列表（blur 与「修改」点击之间若换 DOM，点击会丢）
- 标签栏 chips：`全部 N` / 各标签（按拼音序） / `未分类 N`，事件委托；与搜索叠加
- 搜索命中范围：小名 / 艺名 / 姓名 / **标签**
- 默认标签面板：`全部显示` + 每个标签 checkbox；勾选即写库、筛列表、关面板；header 按钮文案 `🏷 默认：X`
- 默认标签已不在任何档案上 → `resolveDefaultFilter()` 回落 `''`（全部）
- 弹窗：880×560（原 420×480），`max-width:94%`；≤560px 断点自适应
