## 二、变更清单

### Added
- **节气区真太阳两行**：12 节气列由 4 行 → 6 行，在 `.jq-tm`（北京时间）**之后**、`.jq-name` 之前插入

  - `☀ 真太阳时间`（`.jq-tstm`，HH:MM）

- **自动化断言 339 → 393**：`?test=1` 新增 v0.27-T01~T07（真太阳换算锚点 / 行序正则回归 / `lng` 缺省「—」 / 跨日两例 / 三端同步）
- 复用既有 `ALGO.trueSolarTime`（含均时差），**不新增算法、不改排盘口径与干支（D1）**；`algorithm.js` **零改动**

## 五、备注

1. **ext.yml 版本格式**：当前 `clacky ext verify` 的 schema 要求 version 为**纯数字三段**（如 `0.27.0`）；
   带 `v` 前缀会报 `schema.invalid_version`。同机已通过扩展（ziwei-paipan 0.5.0 等）均为纯数字格式。
   对外展示（CHANGELOG / SYSTEM.md / 源码头注释）仍用 `v0.27.0`。
2. **遗留 ERR（非本版范围）**：`bazi-paipan-test`、`qimen-paipan`、`qimen-paipan-test` 三个独立容器
   因历史 `v` 前缀 ext.yml 报 schema ERR，建议另行安排清理，不影响本次发布。
3. **并行功能**：`panels/launcher/view.js` 的改动为「奇门遁甲排盘 / 紫微在线」入口，属**其它并行功能**，
   未纳入本版发布内容（保留在工作树）。
4. **内测不提交**：本次内测发布只更新本地容器代码 + `ext.yml` 升版 + 文档，
   **不 push、不 git commit**；待用户 L4 手动验收确认后再走正式发布（届时统一 commit + 打 `v0.27.0` tag）。
5. **回滚**：如需回滚，基线为 tag `v0.26.0`；`ext.yml` 回 `0.26.0` 即可。
